# Chapter 09 — Circular & Self-Referential Relation

> **Golden Rule:** একটা model যখন **নিজেকেই reference** করে (self-relation), তখন
> hierarchy তৈরি হয়। কিন্তু reference-গুলো যদি **cycle** বানায়, তখন circular
> dependency-র সমস্যা হয় — সেটা break করতে হয়।

```text
Self-relation   → Employee.manager_id → Employee (hierarchy)
Circular        → A → B → C → A (cycle = বিপদ)
```

## 1. Self-Referential Relationship

Employee নিজেকেই reference করে:

```python
from odoo import models, fields


class Employee(models.Model):
    _name = "my.employee"          # Table name

    # id = PK → Odoo auto-create

    name = fields.Char()

    manager_id = fields.Many2one(
        "my.employee",             # comodel = নিজেই নিজে!
        string="Manager",
    )                              # FK → my_employee.id (PK)  ← নিজের PK-কে reference
```

```text
employee.manager_id (FK) → employee.id (PK)
        একই table-এর মধ্যে FK
```

> **Self-referential** = FK যেটা **একই table-এর PK**-কে point করে। Hierarchy তৈরি করতে খুব useful।

## 2. Employee Hierarchy (Tree)

```text
CEO (id=1)
 ├── Manager A (id=2)
 │    ├── Employee 1 (id=4)
 │    └── Employee 2 (id=5)
 │
 └── Manager B (id=3)
      ├── Employee 3 (id=6)
      └── Employee 4 (id=7)
```

### Database

```text
my_employee
-----------------
id (PK)   name        manager_id (FK)
1         CEO         NULL          ← top-level (কোনো manager নেই)
2         Manager A   1
3         Manager B   1
4         Employee 1  2
5         Employee 2  2
6         Employee 3  3
7         Employee 4  3
```

```text
CEO.manager_id = NULL   → hierarchy-র top
Manager A.manager_id = 1 → CEO-এর অধীনে
Employee 1.manager_id = 2 → Manager A-এর অধীনে
```

### Full ASCII — Self relation

```text
  my_employee
┌───────────────────────────────┐
│ id (PK)  ◄─────────────────┐  │
│ name                       │  │
│ manager_id (FK) ───────────┼──┘   ← নিজের PK-কে point করে
└───────────────────────────────┘
```

## 3. Circular Dependency কী?

ধরো:

```text
A → B → C → A
```

```text
A
↓
B
↓
C
↓
A   ← cycle!
```

Application যদি বলে:

```text
A depends on B
B depends on C
C depends on A
```

তাহলে **infinite dependency** তৈরি হয়।

---

## 4. ORM-এ Circular Dependency

```python
class A(models.Model):
    _name = "model.a"
    b_id = fields.Many2one("model.b")   # FK → model_b.id (PK)


class B(models.Model):
    _name = "model.b"
    a_id = fields.Many2one("model.a")   # FK → model_a.id (PK)
```

Simple reference-এর জন্য এটা **technically possible** (error নয়)।

Problem শুরু হয় যখন:

```text
A create → B create → A create → B create...   (infinite create)
```

অথবা:

```text
A.compute() → B.compute() → A.compute()   (infinite compute)
```

## 5. Circular-এর সহজ গল্প

> Ashraful বলছে: "আমার approval-এর জন্য Tanvir-এর approval লাগবে।"
>
> Tanvir বলছে: "আমার approval-এর জন্য Ashraful-এর approval লাগবে।"

```text
Ashraful → Tanvir → Ashraful → Tanvir → ... (কখনো শেষ হয় না)
```

এটাই circular dependency-র real সমস্যা।

---

## 6. Circular Dependency-এর ৪টা Solution

### Solution 1 — Direction ঠিক করো (clear owner)

সবদিক থেকে dependency না বানিয়ে **একটা clear direction** রাখো:

```text
Employee → Manager (এক দিক)
```

দুই দিকেই dependency বানাও না।

---

### Solution 2 — Nullable FK (break point)

```python
manager_id = fields.Many2one("my.employee")   # FK → my_employee.id (PK)
```

Top-level-এ **NULL** দাও:

```text
CEO.manager_id = NULL   → hierarchy এখান থেকে শুরু
```

NULL মানেই "এখানে dependency শেষ" — এটাই cycle break করে।

---

### Solution 3 — Avoid recursive create

**Bad:**

```python
create_A()
    create_B()
        create_A()      # recursive → infinite
```

**Better:**

```python
A create
B reference A           # আগে A বানাও, পরে B-তে A-র id দাও
```

---

### Solution 4 — Use IDs after creation

প্রথমে parent create করো:

```python
a = self.env["model.a"].create({"name": "A"})      # আগে A
```

তারপর child-এ reference দাও:

```python
b = self.env["model.b"].create({
    "name": "B",
    "a_id": a.id,        # FK → model_a.id (PK)  ← created id use
})
```

> আগে তৈরি করে **id নিয়ে** পরে reference দিলে circular creation ভেঙে যায়।

## 7. Tips & Tricks

1. **Self-relation চেনা:** `Many2one("same.model")` — comodel আর নিজের model একই।

2. **Self-relation-এ hierarchy query:**
   ```python
   self.env["my.employee"].search([
       ("manager_id", "=", False),   # top-level (CEO)
   ])
   ```

3. **Circular চেনা:** graph-এ `A → B → C → A` হলে cycle। break করতে একটা nullable FK বা clear direction দাও।

4. **Parent-child relationship = self Many2one + One2many:**
   ```python
   manager_id = fields.Many2one("my.employee")        # FK → parent
   child_ids = fields.One2many("my.employee", "manager_id")  # reverse
   ```

5. **Odoo-তে real example:** `res.partner.parent_id` (parent company), `account.account` hierarchy — সব self-relation।

---

## 8. Quick Recap

```text
Self-relation   → Many2one(নিজের model) → hierarchy
Circular        → A → B → C → A → dependency cycle

Solution:
  1. Direction ঠিক করো
  2. Nullable FK (top-level NULL)
  3. Avoid recursive create
  4. ID create-এর পরে use করো
```

> **Super Rule:** Self-relation ভালো (hierarchy), কিন্তু **cycle বানিও না**। Nullable FK বা clear direction দিয়ে cycle break করো।
