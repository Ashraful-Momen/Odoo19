# Chapter 01 — Database Foundation: PK & FK

> **Golden Rule:** Database relation আগে বুঝবে, তারপর ORM relation বুঝবে।
> ORM database relationship **তৈরি করে না** — ORM হলো database relationship-কে সহজভাবে ব্যবহার করার **interface**।

```text
Database Truth
      ↓
ORM Representation
```

---

## এই Chapter-এ কী শিখবে

- PK (Primary Key) কী, কেন দরকার
- FK (Foreign Key) কী, কীভাবে তৈরি হয়
- DB table-এ PK/FK চেনার উপায়
- Odoo Model-এ PK/FK কীভাবে লেখা হয়

---

## 1. PK (Primary Key)

### Concept

**PK = Primary Key** — একটা table-এর প্রতিটি record-কে **uniquely identify** করে।

একটা প্রশ্ন: `student` table-এ ৩ জনের নাম থাকলে, "Ashraful" কোন record-টা? শুধু নাম দিয়ে চেনা যায় না (নাম duplicate হতে পারে)। তাই একটা column দরকার যেটা **সবসময় unique**।

```text
student
----------------
id    name        ← id = PK
1     Ashraful
2     Tanvir
3     Abdullah
```

```text
1 → শুধু Ashraful
2 → শুধু Tanvir
3 → শুধু Abdullah
```

একই `id` দুইবার থাকতে পারবে **না**। এটাই PK-এর কাজ।

### Tips

> **PK = "আমি কে?"** — প্রতিটা row-এর পরিচয়।

---

## 2. FK (Foreign Key)

### Concept

**FK = Foreign Key** — একটা table-এর column যখন **অন্য table-এর PK**-কে reference করে, সেটাই FK।

FK দিয়ে দুইটা table-এর মধ্যে **relation** তৈরি হয়।

ধরো:

```text
department                          employee
----------------                    -------------------------
id    name                          id    name       dept_id
1     AI                            1     Ashraful   1
2     Software                      2     Tanvir     1
                                    3     Karim      2
```

এখানে `employee.dept_id`-এর মান আসলে `department.id`-কে দেখাচ্ছে:

```text
department.id  ← PK
       ↑
       |   (reference করে)
employee.dept_id  ← FK
```

### Tips

> **FK = "আমি কার সাথে connected?"** — FK সবসময় **অন্য table-এর PK**-কে point করে।

---

## 3. PK + FK একসাথে দেখো (Full ASCII)

```text
  department (PARENT)                    employee (CHILD)
┌──────────────────────┐            ┌─────────────────────────────┐
│ id  (PK) ────────────┼───┐        │ id  (PK)                   │
│ name                 │   │        │ name                        │
└──────────────────────┘   │        │ dept_id (FK) ◄──────────────┤
                           │        └─────────────────────────────┘
                           └──────► reference করে department.id
```

এক লাইনে মনে রাখো:

```text
employee.dept_id (FK)  →  department.id (PK)
```

## 4. Odoo Model-এ PK/FK কীভাবে লেখা হয়

Odoo-তে **তুমি PK manually লেখো না** — Odoo প্রতিটা model-এ `id` নামে একটা PK **auto-create** করে।

```python
from odoo import models, fields


class Department(models.Model):
    _name = "my.department"      # Table name = "my_department" (dot → underscore)

    # id = PK  → Odoo auto-create করে (integer, auto-increment)
    #            DB-তে column: "id"

    name = fields.Char()         # Normal field (কোনো relation নেই)


class Employee(models.Model):
    _name = "my.employee"        # Table name = "my_employee"

    name = fields.Char()         # Normal field

    department_id = fields.Many2one(
        "my.department",
        string="Department",
    )                           # FK → my_department.id (Department-এর PK)
```

### এই code-এ কী কী আছে

| Code | Type | DB-তে কী হয় |
|------|------|--------------|
| `id` (লেখা হয়নি) | **PK** | Odoo auto-create করে |
| `name` | Normal field | normal column |
| `department_id` | **FK** | `my_employee.department_id` column, `my_department.id` reference করে |

> **Odoo-তে FK মানেই `fields.Many2one`।** এই একটা line-ই DB-তে FK column বানিয়ে দেয়।

---

## 5. Tips & Tricks

1. **PK খুঁজবে কীভাবে?** → table-এর `id` column। Odoo-তে সবসময় `id`।

2. **FK খুঁজবে কীভাবে?** → যে column-এর নাম `কিছু_id` (`dept_id`, `manager_id`, `customer_id`) এবং যার মান অন্য table-এর `id`।

3. **কোনটা PK কোনটা FK ভুলে যাও?** → মনে রাখো:
   - PK = **নিজের** identity
   - FK = **অন্যের** PK-এর reference

4. **`_id` suffix = FK-এর strong signal** (Odoo convention-এ `Many2one` field-এর নাম শেষে `_id` থাকে)।

5. **FK সবসময় "Many" side-এ থাকে** — এটা পরের chapter-এ বিস্তারিত বুঝবে, এখন শুধু মাথায় রাখো।

---

## 6. Quick Recap

```text
PK  = Primary Key  = নিজের record-এর unique identity
FK  = Foreign Key  = অন্য table-এর PK-কে reference

Odoo-তে:
  PK  → auto-created "id" field
  FK  → fields.Many2one()
```

> **একটা Super Rule:** কোনো relation বুঝতে হলে **আগে DB-তে FK কোথায় আছে** সেটা খুঁজো। FK পেয়ে গেলে relationship প্রায় নিজে থেকেই বের হয়ে যায়।
