# Chapter 10 — Related vs Computed Field

> **Golden Rule:** `related=` অন্য field-এর value **shortcut** হিসেবে দেখায়।
> `compute=` নিজে **calculation** করে value বানায়।

```text
Related   → অন্য relation-এর field থেকে value আসে (copy shortcut)
Computed  → calculation/logic দিয়ে value তৈরি হয়
```

## 1. Related Field — Shortcut

ধরো Employee-র department-এর name তোমার দরকার। প্রতিবার:

```python
employee.department_id.name
```

লিখতে হয়। এটা repetitive। তার বদলে related field দাও:

```python
from odoo import models, fields


class Department(models.Model):
    _name = "my.department"        # Table name

    name = fields.Char()           # Normal field


class Employee(models.Model):
    _name = "my.employee"          # Table name

    name = fields.Char()

    department_id = fields.Many2one(
        "my.department",
    )                              # FK → my_department.id (PK)

    department_name = fields.Char(
        related="department_id.name",
    )                              # reference → department_id → name (shortcut)
```

### কী হয়

```python
employee.department_name    # → automatically department_id.name
```

```text
employee
   ↓
department_id   (FK)
   ↓
name            (related target)
```

> **`related="department_id.name"` মানে:** "অন্য model-এর ওই field-এর value আমাকে shortcut হিসেবে দেখাও।"

### Related field-এর dotted path

```text
related="department_id.manager_id.name"
          ↓
employee → department → manager → name
```

যত গভীর relation তত dotted path।

## 2. Computed Field — Calculation

Value নিজে calculate করে:

```python
from odoo import models, fields, api


class OrderLine(models.Model):
    _name = "my.order.line"        # Table name

    qty = fields.Float()           # Normal field
    price = fields.Float()         # Normal field

    total = fields.Float(
        compute="_compute_total",
        store=True,                # DB-তে save করবে (optional)
    )                              # computed → qty * price


    @api.depends("qty", "price")
    def _compute_total(self):
        for record in self:
            record.total = record.qty * record.price
```

### কী হয়

```python
line.total   # → automatically qty * price
```

```text
qty (5) × price (100) → total (500)
```

## 3. @api.depends — Dependency

Computed field-কে বলতে হয় **কোন field change হলে recompute** হবে:

```python
@api.depends("qty", "price")
def _compute_total(self):
    for record in self:
        record.total = record.qty * record.price
```

```text
qty changes
      ↓
price changes
      ↓
recompute total
```

> **কেন দরকার?** `@api.depends` ছাড়া Odoo জানবে না কখন total-টা আবার calculate করতে হবে। qty/price বদলালেও total stale হয়ে থাকবে।

### Multiple dependency

```python
@api.depends("qty", "price", "discount")
def _compute_total(self):
    for record in self:
        record.total = (record.qty * record.price) - record.discount
```

## 4. store=True vs store=False

```python
total = fields.Float(
    compute="_compute_total",
    store=True,      # DB-তে column তৈরি → search/filter করা যায় (fast read)
)
```

| store | আচরণ |
|-------|------|
| `store=False` (default) | DB-তে save হয় না, read-এ compute হয় (সবসময় fresh) |
| `store=True` | DB-তে column থাকে, depends change হলে recompute |

> **Tip:** search/group/sort করতে চাইলে `store=True` দাও। শুধু display-এর জন্য `store=False`।

## 5. Related vs Computed — পার্থক্য

### Related

```python
department_name = fields.Char(
    related="department_id.name",
)                              # reference → department_id.name (shortcut)
```

Value **অন্য field থেকে** আসে (কোনো calculation নয়)।

### Computed

```python
total = fields.Float(
    compute="_compute_total",
)                              # computed → qty * price
```

Value **calculation/logic** থেকে আসে।

### Comparison Table

```text
            Related              Computed
সোর্স        অন্য field-এর value    নিজের calculation
কী লেখে      related="..."         compute="_method"
dependency   auto (dotted path)    @api.depends("...")
কখন          value copy shortcut   qty*price, concatenation
```

## 6. Full Example — দুইটাই একসাথে

```python
from odoo import models, fields, api


class SaleOrderLine(models.Model):
    _name = "sale.order.line"

    product_id = fields.Many2one("product.product")   # FK → product_product.id (PK)

    qty = fields.Float()               # Normal field
    price_unit = fields.Float()        # Normal field

    # Related → product-এর name shortcut
    product_name = fields.Char(
        related="product_id.name",
    )                                  # reference → product_id.name

    # Computed → subtotal calculate
    subtotal = fields.Float(
        compute="_compute_subtotal",
        store=True,
    )                                  # computed → qty * price_unit

    @api.depends("qty", "price_unit")
    def _compute_subtotal(self):
        for record in self:
            record.subtotal = record.qty * record.price_unit
```

## 7. Tips & Tricks

1. **Related-এ store চাইলে:**
   ```python
   department_name = fields.Char(related="department_id.name", store=True)
   ```

2. **Computed field সবসময় loop করো:**
   ```python
   def _compute_total(self):
       for record in self:      # recordset-এ loop
           record.total = ...
   ```

3. **Related vs Computed চেনা:**
   - শুধু "অন্য field দেখাও" → `related`
   - "গণনা করো" → `compute`

4. **Related field read-only** (default) — চাইলে `inverse` দিয়ে write-able বানানো যায় (advanced)।

5. **Computed-এ depends miss কোরো না** — নাহলে value stale হয়ে যাবে।

---

## 8. Quick Recap

```text
Related   = related="a.b.c"    → অন্য field-এর shortcut (reference)
Computed  = compute="_method"  → calculation (qty*price)
@api.depends("field")          → কখন recompute হবে

Related  → value copy
Computed → value calculate
```

> **Super Rule:** অন্য relation-এর value শুধু দেখাতে চাইলে `related=`, নিজে হিসাব করতে চাইলে `compute=` + `@api.depends`।
