# Odoo ORM — Complete Relationship Syllabus

## Prerequisites (শুরু করার আগে)

- Basic Python (class, method, loop)
- Basic Odoo model structure (`_name`, `fields`)
- SQL-এর খুব basic ধারণা (SELECT, WHERE) — **must না, helpful**

---

## Core Mental Model (সবসময় মনে রাখবে)

```text
WHO → HAS → HOW MANY → WHERE IS FK

Example:
  Customer → has → Orders → many → FK = order.customer_id
```

> **Super Rule:** কোনো ORM field মুখস্থ করার আগে database-এ **FK কোথায় আছে** সেটা খুঁজে বের করো। FK পেলে relationship প্রায় নিজে থেকেই বের হয়ে যায়।
