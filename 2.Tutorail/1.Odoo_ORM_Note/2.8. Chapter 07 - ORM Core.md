# Chapter 07 — ORM Core (env, Recordset, CRUD, Domain)

> **Golden Rule:** ORM = **Object Relational Mapping** — Python object আর database
> table-এর মাঝের bridge। তুমি SQL লেখো না, Python object-ই database-এ map হয়।

```text
Python Object → ORM → SQL → Database
```

## 1. ORM কী?

**ORM = Object Relational Mapping।**

Database-এ কাজ SQL দিয়ে হয়, ORM-এ Python object দিয়ে:

```sql
-- Database (SQL)
SELECT * FROM employees WHERE id = 10;
```

```python
# ORM (Python)
employee = self.env["hr.employee"].browse(10)
```

```sql
-- Database (SQL)
INSERT INTO employee (...) VALUES (...);
```

```python
# ORM (Python)
self.env["my.employee"].create({"name": "Ashraful"})
```

```text
Python Object
      ↓
ORM
      ↓
SQL
      ↓
Database
```

---

## 2. self.env — সবচেয়ে Important Object

`self.env` = Odoo **environment** (database session + user + context)।

```python
self.env["model.name"]     # যেকোনো model access
```

```python
employees = self.env["hr.employee"]      # employee model-এর recordset (empty)
```

Model access-এর জন্য সবসময় `self.env["model.name"]` ব্যবহার করো।

```python
Employee = self.env["my.employee"]       # model reference
employee = Employee.browse(10)           # specific record
```

---

## 3. Recordset — Odoo-র Unique Concept

**Recordset** = এক বা একাধিক record-এর collection (list-এর মতো, কিন্তু powerful)।

### Single record

```python
employee = self.env["hr.employee"].browse(10)   # ১টা record-এর recordset
```

### Multiple records

```python
employees = self.env["hr.employee"].browse([10, 20, 30])  # ৩টা record-এর recordset
```

### Recordset-এর key points

```text
- Recordset = empty, single, বা multiple record ধরতে পারে
- Loop করা যায়: for emp in employees
- Dotted access একসাথে সব record-এ apply হয়
```

---

## 4. CRUD — ৪টা Basic Operation

### Create

```python
employee = self.env["my.employee"].create({
    "name": "Ashraful",
})                                    # নতুন record → PK (id) auto generate
```

### Read (৩টা উপায়)

```python
# ১) Search → list of ids (domain match করা সব record)
employees = self.env["my.employee"].search([
    ("name", "=", "Ashraful"),
])

# ২) Browse → নির্দিষ্ট id
employee = self.env["my.employee"].browse(10)

# ৩) search + count / read
count = self.env["my.employee"].search_count([("active", "=", True)])
```

### Update (Write)

```python
employee.write({
    "name": "Md Ashraful Momen",
})                                    # existing record update
```

### Delete (Unlink)

```python
employee.unlink()                     # record delete (PK id মুছে যায়)
```

### CRUD Summary

```text
Create  → .create({...})
Read    → .search(domain) / .browse(id)
Update  → .write({...})
Delete  → .unlink()
```

## 5. Domain — Filter Syntax

Domain = Odoo-র search filter। Format:

```python
[("field", "operator", "value")]
```

### Single condition

```python
employees = self.env["hr.employee"].search([
    ("active", "=", True),
])
```

### Multiple condition (AND)

```python
employees = self.env["hr.employee"].search([
    ("active", "=", True),
    ("department_id.name", "=", "AI"),
])
```

### Common operators

```text
=           equal
!=          not equal
> , <       greater / less
>= , <=     greater-equal / less-equal
in          value-এর list-এ আছে [("id", "in", [1,2,3])]
not in      list-এ নেই
like        partial match (contains)
=like       case-insensitive like
child_of    hierarchical children
```

## 6. Relation Traversal (Powerful)

ORM dotted access দিয়ে relation **traverse** করা যায়:

```python
employee.department_id.manager_id.name
```

```text
Employee
   ↓
Department
   ↓
Manager
   ↓
Name
```

Domain-এও relation traverse করা যায়:

```python
employees = self.env["hr.employee"].search([
    ("department_id.manager_id.name", "=", "Tanvir"),
])
```

```text
employee
   ↓
department_id  (FK → department)
   ↓
manager_id     (FK → manager)
   ↓
name
```

> **Tip:** dotted access-এ Many2one/One2many relation **auto-follow** হয়। এটাই ORM-এর power — তোমাকে JOIN লিখতে হয় না।

---

## 7. Full Example — সব একসাথে

```python
# Create
dept = self.env["my.department"].create({"name": "AI"})        # new record

# Create (FK দিয়ে relation)
employee = self.env["my.employee"].create({
    "name": "Ashraful",
    "department_id": dept.id,          # FK → my_department.id (PK)
})

# Search + Relation traversal
result = self.env["my.employee"].search([
    ("department_id.name", "=", "AI"),
])

# Write (update)
result.write({"name": "Md Ashraful"})

# Reverse access (One2many)
dept.employee_ids                    # → এই department-এর সব employee (reverse view)

# Delete
employee.unlink()
```

## 8. Tips & Tricks

1. **`self.env` সব জায়গায় কাজ করে** — model method, wizard, report — সবখানে `self.env`.

2. **Browse vs Search:**
   ```text
   browse(id)   → id জানা থাকলে (fast, direct)
   search(domain) → filter দিয়ে খুঁজতে হলে
   ```

3. **Recordset-এ loop করো, id-এ না:**
   ```python
   for emp in employees:       # ভালো (recordset)
       emp.write({...})
   ```

4. **FK set করতে record pass করা যায়:**
   ```python
   "department_id": dept       # record object (Odoo নিজে id নেয়)
   "department_id": dept.id    # বা সরাসরি id
   ```

5. **Dotted access = automatic JOIN** — `employee.department_id.name` SQL-এর JOIN equivalent।

## 9. Quick Recap

```text
ORM        = Python object ↔ DB table bridge
self.env   = environment → model access
Recordset  = record collection (single/multiple)
CRUD       = create / search-browse / write / unlink
Domain     = [("field", "operator", "value")]
Traversal  = dotted access (auto relation follow)
```

> **Super Rule:** `self.env["model"].create/search/browse/write/unlink` + dotted traversal — এই ৬টা জানলে Odoo-তে ৯০% data operation করতে পারবে।
