# Chapter 02 — Cardinality & Relationship Overview

> **Golden Rule:** যেকোনো system দেখলে শুধু **একটা প্রশ্ন** করো —
> **"একটা A-এর সাথে কতগুলো B থাকতে পারে?"** এই প্রশ্নের উত্তরই relationship-এর type।

```text
PK / FK (Chapter 01)
      ↓
Golden Question (এই chapter)
      ↓
১:১ / ১:এন / এম:এন (Chapter 03-05)
```

## 1. Cardinality কী?

**Cardinality** = দুইটা entity-এর মধ্যে record-সংখ্যার সম্পর্ক।

সবসময় এই প্রশ্ন দিয়ে শুরু করো:

> **একটা A-এর সাথে কতগুলো B থাকতে পারে?**

তারপর reverse-ও জিজ্ঞেস করো:

> **একটা B-এর সাথে কতগুলো A থাকতে পারে?**

দুই দিকের উত্তর দিলেই cardinality বেরিয়ে আসে।

---

## 2. Golden Question-এর উদাহরণ

### Department vs Employee

```text
প্রশ্ন ১: একটা Department-এ কত Employee?
উত্তর:   অনেক (many)

প্রশ্ন ২: একজন Employee কয়টা Department-এ?
উত্তর:   একটা (one)
```

তাহলে:

```text
Department 1 ───── N Employee
```

এটাই **One-to-Many (১:এন)**।

### Student vs Course

```text
প্রশ্ন ১: একজন Student কত Course নিতে পারে?
উত্তর:   অনেক (many)

প্রশ্ন ২: একটা Course-এ কত Student?
উত্তর:   অনেক (many)
```

তাহলে:

```text
Student M ───── N Course
```

এটাই **Many-to-Many (এম:এন)**।

### Employee vs Passport

```text
প্রশ্ন ১: একজন Employee-এর কত Passport?
উত্তর:   একটা (one)

প্রশ্ন ২: একটা Passport কার?
উত্তর:   একজন Employee-এর (one)
```

তাহলে:

```text
Employee 1 ───── 1 Passport
```

এটাই **One-to-One (১:১)**।

## 3. Three Main Relationships (90% এর সব)

```text
1. One-to-One    (১:১)   →  Many2one + unique
2. One-to-Many   (১:এন)  →  Many2one + One2many
3. Many-to-Many  (এম:এন) →  Many2many + Pivot table
```

আর এগুলোর উপর ভিত্তি করে advanced আসে (পরের chapter-এ):

```text
Polymorphic / Generic
Self / Circular
```

## 4. Relationship-এর ASCII Map

```text
১:১ (One-to-One)

   Employee 1 ═══════ 1 Passport

   FK + UNIQUE on Passport side


১:এন (One-to-Many)

   Department 1 ────< N Employee

   FK on Employee (many) side


এম:এন (Many-to-Many)

   Student M >────< N Course
                │
           Pivot Table
         (student_course)
```

## 5. DB Table-এ Relationship চেনার উপায়

মূল জিনিস: **FK কোথায় আছে** দেখো।

### ১:১

```text
employee                        passport
--------------                  ----------------
id (PK)                         id (PK)
name                            passport_no
                                employee_id (FK + UNIQUE)
```

> **FK যেখানে, সেখানেই relation বসে।** ১:১-তে FK **UNIQUE** হয়।

### ১:এন

```text
department                      employee
--------------                  ----------------
id (PK)                         id (PK)
name                            name
                                department_id (FK)  ← "Many" side-এ FK
```

> **১:এন-এ FK থাকে "Many" side-এ।**

### এম:এন

```text
student         pivot table            course
---------       ---------------        ---------
id (PK)         student_id (FK)        id (PK)
name            course_id  (FK)        name
```

> **এম:এন-এ আলাদা একটা pivot table লাগে**, কারণ একটা column-এ multiple value রাখা যায় না।

## 6. Odoo Model-এ ৩টা Type (Overview)

এখন শুধু overview — বিস্তারিত Chapter 03-05-এ।

```python
from odoo import models, fields


# ১:১ — Many2one + unique constraint
class Employee(models.Model):
    _name = "my.employee"        # Table name

    name = fields.Char()

    passport_id = fields.Many2one(
        "my.passport",
        string="Passport",
    )                            # FK → my_passport.id (PK)


# ১:এন — Many2one (FK) + One2many (reverse)
class Department(models.Model):
    _name = "my.department"      # Table name

    name = fields.Char()

    employee_ids = fields.One2many(
        "my.employee",
        "department_id",
        string="Employees",
    )                            # reference → my_employee.department_id (reverse view)


class Employee(models.Model):
    _name = "my.employee"        # Table name

    name = fields.Char()

    department_id = fields.Many2one(
        "my.department",
        string="Department",
    )                            # FK → my_department.id (PK)


# এম:এন — Many2many
class Student(models.Model):
    _name = "my.student"         # Table name

    name = fields.Char()

    course_ids = fields.Many2many(
        "my.course",
        string="Courses",
    )                            # relation → pivot table (student_course_rel)
```

### Code-এ কী কী দেখলে

| Field | Type | DB-তে |
|-------|------|-------|
| `passport_id` | Many2one | **FK** |
| `department_id` | Many2one | **FK** |
| `employee_ids` | One2many | **reverse reference** (নিজে FK রাখে না) |
| `course_ids` | Many2many | **pivot table** relation |

## 7. Powerful Mental Model — ৪ ধাপ

প্রতিটা relation-কে এই format-এ চিন্তা করো:

```text
WHO
 ↓
HAS
 ↓
HOW MANY
 ↓
WHERE IS FK
```

### Example

```text
Customer
   ↓
has
   ↓
Orders
   ↓
many
   ↓
FK = order.customer_id
```

এই ৪টা ধাপ করলেই যেকোনো relation decode হয়ে যাবে।

## 8. Tips & Tricks

1. **দুই দিকেই প্রশ্ন করো** — এক দিক বললেই হবে না। "A → B" আর "B → A" দুটোই দেখো।

2. **"একটা" vs "অনেক"** — শুধু এই দুইটা শব্দ মাথায় রাখো। উত্তর সবসময় `one` বা `many`।

3. **FK খুঁজেই type বের করো** — FK পেলে relationship প্রায় নিজে থেকেই বের হয়।

4. **Quick 결정ের টেবিল:**

   ```text
   A-side    B-side    →  Relationship
   ----------------------------------
   one       one       →  ১:১
   one       many      →  ১:এন
   many      many      →  এম:এন
   ```

5. **১:এন আর এম:এন confuse হলে** — জিজ্ঞেস করো: "B-এর একটা record কি একাধিক A-এর সাথে যুক্ত হতে পারে?"
   - না → ১:এন
   - হ্যাঁ → এম:এন

---

## 9. Quick Recap

```text
Cardinality = "একটা A-এর সাথে কতগুলো B?"

১:১   = one ↔ one   = Many2one + unique
১:এন  = one → many  = Many2one + One2many (FK on many side)
এম:এন = many ↔ many = Many2many + pivot table

Mental model = WHO → HAS → HOW MANY → WHERE IS FK
```

> **Super Rule:** FK কোথায় আছে সেটা খুঁজো — type নিজে থেকেই বের হয়ে যাবে।
