# Chapter 05 — Many-to-Many (এম:এন) Relationship

> **Golden Rule:** Database সরাসরি এম:এন store করতে পারে না। মাঝখানে একটা
> **Pivot/Junction table** লাগে। Odoo-তে এটা `Many2many` field-এর কাজ।

```text
এম:এন  =  Many2many  +  Pivot Table
```

---

## এই Chapter-এ কী শিখবে

- এম:এন relationship-এর story
- Database-এ pivot table কেন দরকার
- Odoo `Many2many` (auto pivot)
- Explicit pivot table (advanced)
- Full ASCII + Tips

## 1. Story

> একজন **Student** অনেক **Course** নিতে পারে।
> একটা **Course**-এ অনেক **Student** থাকতে পারে।

```text
Student A ─── Course 1
          ├── Course 2
          └── Course 3

Student B ─── Course 1
          └── Course 3
```

```text
Student M ───── N Course
```

দুই দিকেই **অনেক** → তাই এম:এন।

---

## 2. Database-এ এম:এন কেন সরাসরি হয় না?

দুইটা table দিয়ে এম:এন efficiently store করা যায় না।

একটা column-এ একটা মাত্র value রাখা যায়, অনেক না।

```text
student                        course
---------                      ---------
id (PK)                        id (PK)
name                           name
```

"Student A → Course 1, 2, 3" এটাকে একটা column-এ লেখা যায় না।

### Solution → মাঝখানে Pivot Table

```text
student         pivot table            course
---------       ---------------        ---------
id (PK)         student_id (FK)        id (PK)
name            course_id  (FK)        name
```

> **Pivot / Junction / Association table** = দুটো FK মিলিয়ে একটা relation record।

---

## 3. Pivot Table-এর Data

```text
students                     courses
1 Ashraful                   10 Laravel
2 Tanvir                     20 Odoo
                             30 AI
```

Pivot:

```text
student_course
----------------
student_id (FK)   course_id (FK)
1                 10
1                 20
1                 30
2                 20
```

```text
Ashraful → Laravel
Ashraful → Odoo
Ashraful → AI
Tanvir   → Odoo
```

### Full ASCII — এম:এন relationship

```text
  student (PK)            pivot table               course (PK)
┌───────────────┐     ┌──────────────────────┐   ┌───────────────┐
│ id (PK) ◄─────┼─────┤ student_id (FK)      │   │ id (PK) ◄─────┼──┐
│ name          │     │ course_id  (FK) ─────┼──►│ name          │  │
└───────────────┘     └──────────────────────┘   └───────────────┘  │
                                                                     │
        প্রতিটা row = "এই student এই course নেয়" ◄────────────────────┘
```

## 4. Odoo Many2many (Auto Pivot)

Odoo automatically pivot table manage করে:

```python
from odoo import models, fields


class Student(models.Model):
    _name = "my.student"           # Table name (DB: my_student)

    # id = PK → Odoo auto-create

    name = fields.Char()           # Normal field

    course_ids = fields.Many2many(
        "my.course",
        string="Courses",
    )                              # relation → auto pivot table (student_course_rel)


class Course(models.Model):
    _name = "my.course"            # Table name (DB: my_course)

    # id = PK → Odoo auto-create

    name = fields.Char()           # Normal field

    student_ids = fields.Many2many(
        "my.student",
        string="Students",
    )                              # relation → auto pivot table (reverse side)
```

### DB-তে Odoo যা করে

```text
my_student          my_student_course_rel          my_course
-----------         ---------------------          ---------
id (PK)             student_id (FK)                id (PK)
name                course_id  (FK)                name
```

> Odoo **নিজে** `student_course_rel` নামে pivot table বানায়।

## 5. Explicit Pivot Table (Advanced)

তুমি চাইলে relation table-এর **নাম ও column** নিজে define করতে পারো:

```python
course_ids = fields.Many2many(
    "my.course",            # comodel (target model)
    "student_course_rel",   # pivot table-এর নাম (explicit)
    "student_id",           # এই model-এর FK column name (pivot-এ)
    "course_id",            # target model-এর FK column name (pivot-এ)
    string="Courses",
)                           # relation → student_course_rel(student_id, course_id)
```

### ৫টা argument-এর মানে

```text
Many2many(comodel, relation_table, column1, column2, ...)
              ↑          ↑            ↑        ↑
           target      pivot table   নিজের FK  target-এর FK
```

```text
student_course_rel
-------------------
student_id (FK) → my_student.id (PK)
course_id  (FK) → my_course.id  (PK)
```

---

## 6. Auto vs Explicit Pivot — কখন কোনটা

| Situation | ব্যবহার |
|-----------|---------|
| শুধু relation দরকার (কোনো extra data নেই) | Auto `Many2many` |
| relation table-এর নাম control চাই | Explicit table name |
| relation-এ **extra data** লাগবে (grade, date...) | ❌ Many2many না → Chapter 06 |

---

## 7. Tips & Tricks

1. **এম:এন মনে রাখার trick:**
   ```text
   MANY ↔ MANY
   = Many2many + Pivot table
   ```

2. **Pivot table-এ PK?** → সাধারণত pivot table-এ আলাদা PK থাকে না (বা composite)। দুটো FK-ই identity।

3. **এম:এন চেনা:** "B-এর একটা record কি একাধিক A-এর সাথে যুক্ত?" → হ্যাঁ = এম:এন।

4. **Odoo auto pivot-এর default নাম:** `{model1}_{model2}_rel` — কিন্তু explicit দিলে predictable হয়।

5. **দুই দিকের field রাখা লাগে না** — একদিকে `Many2many` দিলেই relation কাজ করে; অন্যদিকে reverse access চাইলে আরেকটা `Many2many` দাও (Odoo একই pivot table use করে)।

---

## 8. Quick Recap

```text
এম:এন
  ↓
Many ↔ Many
  ↓
Pivot / Junction table (student_id + course_id)
  ↓
Odoo: fields.Many2many()  →  auto pivot table
```

> **Super Rule:** এম:এন = মাঝে pivot table। শুধু relation চাইলে `Many2many`, relation-এ extra data চাইলে explicit model (Chapter 06)।
