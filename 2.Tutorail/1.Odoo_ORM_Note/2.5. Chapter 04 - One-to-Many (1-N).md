# Chapter 04 — One-to-Many (১:এন) Relationship

> **Golden Rule:** ১:এন-এর **FK সবসময় "Many" side-এ** থাকে।
> আর Odoo-তে ১:এন = **`Many2one` (FK রাখে) + `One2many` (reverse view)**।

```text
১:এন  =  Many2one (store FK)  +  One2many (read reverse)
```

---

## এই Chapter-এ কী শিখবে

- ১:এন relationship-এর story ও DB structure
- **Many2one** — FK কোথায় ও কীভাবে store হয়
- **One2many** — reverse view, কেন নিজে FK রাখে না
- Odoo model code (FK/PK/reference comment সহ)
- সবচেয়ে গুরুত্বপূর্ণ Odoo concept + Tips

---

## 1. Story

> একজন **Manager**-এর অনেক **Employee** থাকে।

```text
Manager
   │
   ├── Employee 1
   ├── Employee 2
   ├── Employee 3
   └── Employee 4
```

```text
Manager 1 ───── N Employee
```

এটাই **১:এন** — Odoo-তে **সবচেয়ে গুরুত্বপূর্ণ** relationship (প্রায় ৮০% ব্যবহার এটাই)।

---

## 2. Database Structure

```text
manager                        employee
--------------                 ------------------
id (PK)                        id (PK)
name                           name
                               manager_id (FK)
```

FK:

```text
employee.manager_id (FK)  →  manager.id (PK)
```

> **Golden Rule:** ১:এন-এ FK থাকে **"Many" side-এ** (এখানে `employee` table-এ)।

### Full ASCII — ১:এন relationship

```text
  manager (ONE)                    employee (MANY)
┌──────────────────────┐        ┌──────────────────────────────────┐
│ id (PK) ◄────────────┼────────┤ id (PK)                         │
│ name                 │        │ name                            │
└──────────────────────┘        │ manager_id (FK) ◄───────────────┤
                                └──────────────────────────────────┘
    একজন manager → অনেক employee (FK employee-র manager_id-তে)
```

---

## 3. Odoo Model — Many2one (FK side)

`employee` model-এ FK থাকে:

```python
from odoo import models, fields


class Employee(models.Model):
    _name = "my.employee"          # Table name (DB: my_employee)

    # id = PK → Odoo auto-create করে

    name = fields.Char()           # Normal field

    manager_id = fields.Many2one(
        "my.manager",
        string="Manager",
    )                              # FK → my_manager.id (PK)  ← FK এখানে store হয়
```

- `manager_id` DB-তে একটা **integer column** → `my_manager.id`-এর মান রাখে।
- এটা "একজন manager select করবে"।

---

## 4. Odoo Model — One2many (reverse side)

`manager` model-এ reverse view:

```python
class Manager(models.Model):
    _name = "my.manager"           # Table name (DB: my_manager)

    # id = PK → Odoo auto-create করে

    name = fields.Char()           # Normal field

    employee_ids = fields.One2many(
        "my.employee",             # comodel  = "many" side model
        "manager_id",              # inverse  = FK field-এর নাম (employee model-এর)
        string="Employees",
    )                              # reference → my_employee.manager_id (reverse view)
```

### One2many-এর ৩টা argument

```python
fields.One2many(
    comodel_name,   # কোন model-কে reverse দেখাবে ("many" side)
    inverse_name,   # ওই model-এর কোন FK field-টা point back করে
    string="...",   # UI label
)
```

```text
employee_ids = One2many("my.employee", "manager_id")
                          ↑               ↑
                     "many" model      FK field on employee
```

---

## 5. সবচেয়ে Important Odoo Concept

এই ২টা relation **একই relationship-এর দুই দিক**:

```text
Employee
    |
    | manager_id (Many2one)  → FK store করে
    ↓
Manager

Manager
    |
    | employee_ids (One2many) → reverse পড়ে
    ↓
Employee
```

```text
Many2one  = database side-এর মূল relation (FK store করে)
One2many  = তার reverse view (শুধু পড়ে)
```

> **মনে রাখো:**
> **Many2one stores the FK. One2many reads the reverse side.**
> এটা মাথায় বসলে Odoo ORM-এর অর্ধেক শেষ।

---

## 6. One2many কেন FK রাখে না?

খুব গুরুত্বপূর্ণ প্রশ্ন। তুমি লিখলে:

```python
employee_ids = fields.One2many("my.employee", "manager_id")
```

Odoo **database-এ `employee_ids` নামে কোনো column তৈরি করে না**।

বরং Odoo internally (যখন `manager.employee_ids` access করো):

```sql
SELECT *
FROM my_employee
WHERE manager_id = <manager.id>;
```

```text
Many2one  → FK (আসল column)
One2many  → Reverse lookup (কোনো column নেই)
```

> একই relationship দুইবার store করা **redundant** — তাই FK শুধু এক জায়গায় (Many2one-এ) থাকে।

## 7. Full Code + DB Side-by-side

```python
class Manager(models.Model):
    _name = "my.manager"           # DB: my_manager

    name = fields.Char()

    employee_ids = fields.One2many(
        "my.employee", "manager_id",
    )                              # reference → reverse view (no column)


class Employee(models.Model):
    _name = "my.employee"          # DB: my_employee

    name = fields.Char()

    manager_id = fields.Many2one(
        "my.manager",
    )                              # FK → my_manager.id (PK)  ← একমাত্র column
```

DB-তে আসলে তৈরি হয়:

```text
my_manager                      my_employee
--------------                  ------------------------
id (PK)                         id (PK)
name                            name
                                manager_id (FK)  ← শুধু এটাই column
```

`employee_ids` DB-তে নেই — এটা শুধু Python-এ reverse access।

## 8. Tips & Tricks

1. **FK কোথায়?** → সবসময় **"Many" side**-এ। "একজন manager" → "অনেক employee" → FK employee-তে।

2. **নাম convention:**
   ```text
   Many2one  → নাম শেষে _id   (manager_id)
   One2many  → নাম শেষে _ids  (employee_ids)
   ```

3. **One2many-এর inverse ঠিক করো:** One2many-এর ২য় argument **অবশ্যই** comodel-এর Many2one field-এর নাম হতে হবে।

4. **একই relationship দুই দিক থেকে:**
   ```python
   employee.manager_id          # → manager record (Many2one)
   manager.employee_ids         # → employee records (One2many)
   ```

5. **১:এন মনে রাখার trick:**
   ```text
   ONE → MANY
   FK on MANY side
   = Many2one + One2many
   ```

---

## 9. Quick Recap

```text
১:এন
  ↓
One → Many
  ↓
FK on MANY side
  ↓
Many2one (store FK)  +  One2many (reverse view)

Many2one  → FK column তৈরি করে
One2many  → কোনো column তৈরি করে না (reverse lookup)
```

> **Super Rule:** FK সবসময় "Many" side-এ। One2many নিজে FK রাখে না — reverse lookup করে।
