# Setup Step 3 : Branch Setup (Multi-Branch)

**Series: Odoo 19 ERP Perfect Setup (Step 3 of 11) — File 0.7.1**

> **একটা Company-র তিনটা অফিস — ঢাকা, চট্টগ্রাম, সিলেট। প্রতিটার আলাদা Stock, আলাদা Sales, আলাদা Manager। কিন্তু মালিক এক, Tax এক, Report এক। এই "আলাদা কিন্তু এক" সমস্যার সমাধানই Branch Setup।**

---

# Chapter 1 : আগে বুঝো — Branch কী, কী না

## Real Life Story

```
তোমার Software Company-র Head Office ঢাকায়।

নতুন Branch খুললে চট্টগ্রামে —

   আলাদা Team

   আলাদা ছোট Stock (Laptop, Accessories)

   নিজের Client-দের Invoice
```

প্রশ্ন—

**চট্টগ্রামকে কি আলাদা Company বানাবো?**

```
না!

কারণ—

   আইনি সত্তা একটাই (একটাই TIN/VAT)

   মালিক এক

   Profit হিসাব এক
```

চট্টগ্রাম হলো—

# Branch

```
Company  → আইনি সত্তা (Tax, Report, Balance Sheet)

Branch   → Company-র নিচের Operating Unit

          (নিজের Stock, নিজের Sales, নিজের Manager)
```

---

## Branch বনাম Multi Company — কোনটা কখন

| বিষয় | Branch | Multi Company |
|---|---|---|
| আইনি সত্তা | একটাই | আলাদা আলাদা |
| TIN/VAT Number | একটাই | আলাদা |
| COA / Tax | Shared | আলাদা |
| Report | একসাথে + Branch-ভিত্তিক | আলাদা + Consolidation |
| Stock | আলাদা করা যায় | পুরো আলাদা |
| কখন | একই ব্যবসার অনেক অফিস | আলাদা আইনি ব্যবসা |

> **Rule: একটাই Trade License হলে → Branch। আলাদা License হলে → Multi Company (Module 14)।**

# Chapter 2 : Odoo-তে Branch কীভাবে কাজ করে

## Odoo 18+/19-এ Branch Feature

```
Settings

↓

Users & Companies

↓

Companies

↓

Main Company খোলো

↓

Branches Tab → Add a Branch
```

Odoo Branch-কে "Child Company" হিসেবে রাখে—

```
Parent Company (Head Office)

   ├── Branch A (ঢাকা)

   ├── Branch B (চট্টগ্রাম)

   └── Branch C (সিলেট)
```

```
কী Shared থাকে:

   ✅ COA, Tax, Fiscal Year, Currency

   ✅ Customer/Vendor (Partner)

   ✅ Product Catalog

কী আলাদা করা যায়:

   ✅ Warehouse/Stock

   ✅ Sales Order / Invoice (Branch Tag সহ)

   ✅ User Access (কে কোন Branch দেখবে)

   ✅ Branch-ভিত্তিক Report (Analytic দিয়ে)
```

# Chapter 3 : Branch বানানো — Step by Step

## Step 1 : Multi Company চালু

```
Settings → General Settings → Multi Company চালু
```

```
কেন: Branch technically Child Company

     → Multi Company ছাড়া Branch Option আসে না

না করলে: Branches Tab-ই দেখাবে না
```

## Step 2 : Parent Company খোলো

```
Settings → Users & Companies → Companies

→ তোমার Main Company-তে Click
```

## Step 3 : Branch Add

```
Branches Tab → "Add a line" / New

ভরো—

   Name        → CTG Branch

   Address     → চট্টগ্রামের ঠিকানা

   Email/Phone → Branch-এর Contact
```

```
করলে কী হয়:

   ✅ নতুন Branch তৈরি

   ✅ Company Selector-এ Branch আসে

   ✅ COA/Tax নিজে Share হয়ে যায় (কিছু করতে হয় না)
```

## Step 4 : User Access ঠিক করো

```
Settings → Users → User খোলো

→ Allowed Companies-এ কোন Branch দেবে ঠিক করো
```

```
যেমন—

   CTG Manager → শুধু CTG Branch

   Head Office Accountant → সব Branch

   তুমি (Team Lead) → সব
```

```
করলে কী হয়:

   ✅ CTG Manager শুধু নিজের Branch-এর

      Order/Invoice দেখে

   ✅ ভুল করে অন্য Branch-এ Entry করতে পারে না
```

# Chapter 4 : Branch-এর সাথে Warehouse জোড়া (গুরুত্বপূর্ণ)

```
প্রতিটা Branch-এর নিজের Stock চাইলে

→ প্রতিটা Branch-এ আলাদা Warehouse বানাও
```

```
Inventory → Configuration → Warehouses → New

   Name    → CTG Warehouse

   Company → CTG Branch
```

```
করলে কী হয়:

   ✅ ঢাকার Stock আর CTG-র Stock আলাদা দেখা যায়

   ✅ CTG-র Sales Order → CTG Warehouse থেকে Deliver

না করলে কী হয়:

   ❌ সব Stock এক জায়গায় মিশে যায়

   ❌ কোন Branch-এ কী আছে — কেউ জানে না
```

> **Rule: Branch আছে + Stock আছে = প্রতি Branch-এ আলাদা Warehouse। (বিস্তারিত পরের File 0.7.2-তে)**

# Chapter 5 : Branch-ভিত্তিক Report কীভাবে পাবে?

## Option 1 : Company/Branch Switch করে দেখা

```
উপরে Company Selector → Branch Select

→ ওই Branch-এর Order/Invoice দেখাবে
```

## Option 2 : Analytic Account দিয়ে (Recommended)

```
প্রতিটা Branch-এর জন্য একটা Analytic Account—

   Analytic: DHK

   Analytic: CTG

   Analytic: SYL
```

```
প্রতিটা Invoice/Bill-এ Branch-এর Analytic Tag

→ Reporting → Analytic Report

→ Branch-ভিত্তিক Income/Expense/Profit ✅
```

```
করলে কী হয়:

   মালিক জিজ্ঞেস করলে "CTG Branch লাভে আছে?"

   → ১ মিনিটে উত্তর
```

# Chapter 6 : Branch কখন বানাবে না

```
❌ একটাই অফিস → Branch দরকার নেই

❌ ভার্চুয়াল Team (সবাই Remote, এক জায়গা থেকে কাজ)

❌ শুধু Department আলাদা করতে চাইলে

   → ওটা Branch না, Analytic Account/Cost Center
```

> **Branch মানে Physical Operating Unit — নিজের Stock/Team/Client থাকে এমন জায়গা।**

# Common Mistakes

❌ Branch-কে আলাদা Company বানিয়ে ফেলা — COA/Tax দ্বিগুণ Setup লাগে, Consolidation ঝামেলা।

❌ Multi Company চালু না করে Branch খোঁজা — Option-ই আসে না।

❌ প্রতি Branch-এ Warehouse না দেওয়া — Stock মিশে যায়।

❌ সব User-কে সব Branch-এর Access দেওয়া — ভুল Branch-এ Entry ঢুকে যায়।

❌ Branch-ভিত্তিক হিসাব চাইলেও Analytic Setup না করা — পরে Report পাওয়া যায় না।

❌ Branch-এর নামে আলাদা Invoice Sequence আশা করা — Default-এ Sequence Company-র, Branch-wise চাইলে Custom/OCA লাগে।
