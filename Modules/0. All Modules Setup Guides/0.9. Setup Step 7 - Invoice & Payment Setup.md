# Setup Step 7 : Invoice & Payment Setup

**Series: Odoo 19 ERP Perfect Setup (Step 7 of 11) — File 0.7.5**

> **পণ্য/Service বিক্রি করলেও টাকা আসে Invoice আর Payment দিয়ে। এই দুইটা ঠিক থাকলে — Invoice নিজে যায়, Payment নিজে আসে, পাওনা নিজে মনে করিয়ে দেয়। ভুল থাকলে — বিক্রি আছে, টাকা নেই।**

# PART A : Invoice Setup

## 1. Invoice Layout / Document Format

```
Settings → General Settings → Configure Document Layout

(File 0.7-এ Details দেওয়া আছে)
```

```
এখানে Check করো—

   ✅ Company Logo বসে আছে

   ✅ VAT/TIN Number ছাপছে

   ✅ Payment Terms নিচে আসছে

   ✅ Bank Details Footer-এ আছে ← এটা না থাকলে

      Customer টাকা পাঠাবে কোথায়?
```

> **🚨 Invoice-এ Bank Details না থাকলে Customer-এর Payment আটকে যায় — "কোন Account-এ পাঠাব?" জিজ্ঞেস করতে করতে ১৫ দিন চলে যায়।**

---

## 2. Invoice-এর Default Terms

```
Accounting → Configuration → Settings

→ Customer Invoices → Default Terms & Conditions
```

```
লিখে দাও—

   "Payment due within 30 days of invoice date.

    Late payment subject to 2% monthly interest.

    All disputes subject to Dhaka jurisdiction."
```

```
করলে কী হয়:

   ✅ প্রতিটা Invoice-এ নিজে যায়

   ✅ ঝগড়া হলে তোমার পক্ষে লিখিত প্রমাণ

না করলে: মুখের কথা — Court-এ কাজ করে না
```

# PART B : Payment Acquirer (Online Payment)

## কী জিনিস

```
Invoice-এর সাথে Payment Link/QR যায়

→ Customer Click করেই Pay করে

→ Payment নিজে Odoo-তে ঢুকে Reconcile হয়ে যায়
```

## কোথায়

```
Accounting → Configuration → Payment Acquirers
```

## Setup Steps

```
১. তোমার দেশে চলা Acquirer বেছে নাও

   (Stripe / SSLCommerz / bKash Gateway / PayPal)

২. Acquirer-এর Website থেকে API Key নাও

৩. Odoo-তে Key বসাও

৪. প্রথমে Test Mode-এ চালাও

৫. Test Payment সফল হলে Live Mode
```

```
করলে কী হয়:

   ✅ Payment ২-৩ গুণ দ্রুত আসে

   ✅ Auto Reconcile — Accounting-এ হাত লাগে না
```

```
না করলে কী হয়:

   Manual Bank Transfer-এ চলে — কাজ চলে, ধীরে

মনে রাখবে:

   ⚠️ প্রতিটা Transaction-এ Gateway Fee (১.৫-৩%)

   → হিসাব করে দাম ঠিক করো

   ⚠️ Test Mode থেকে Live করতে ভুলো না —

      নইলে Customer Pay করছে, টাকা যাচ্ছে না
```

## 5. Payment Terms (Customer Side)

```
File 0.10-এ বিস্তারিত আছে — এখানে সারাংশ:

   ✅ Net 30 (বা তোমার Standard) বানানো

   ✅ প্রতিটা Customer-এর Profile-এ Default বসানো

   ✅ Advance লাগলে "50% Advance + 50% Net 30" বানানো
```

```
না করলে:

   ❌ Due Date নেই → Aged Receivable অর্থহীন

   ❌ "কবে টাকা আসবে" — কেউ জানে না

   ❌ পাওনা আদায় = Customer-এর দয়ার উপর
```

# PART C : Follow-up (পাওনা আদায়ের Automatic System)

## কী জিনিস

```
Due Date পার হয়ে গেলে

Odoo নিজে Customer-কে Reminder পাঠায়

→ তোমাকে লজ্জা নিয়ে ফোন করতে হয় না
```

## কোথায়

```
Accounting → Configuration → Follow-up Levels
```

## Setup — Level ধরে ধরে

```
Level 1: Due-এর ৩ দিন পর

   → নরম Email: "Invoice-টা Due হয়ে গেছে,

      Payment-এর কথা মনে করিয়ে দিলাম।"
```

```
Level 2: ১৫ দিন পর

   → একটু শক্ত Email + Statement সংযুক্ত
```

```
Level 3: ৩০ দিন পর

   → Letter / ফোন করার Task তৈরি হবে
```

```
করলে কী হয়:

   ✅ কেউ ভুলে গেলে System মনে করিয়ে দেয়

   ✅ পুরোনো পাওনা জমে থাকে না

   ✅ Follow-up Report-এ দেখো কার কত দিন Late
```

```
না করলে:

   ❌ ৬০ দিনের পাওনা চোখেই পড়ে না

   ❌ বছর শেষে দেখো — ডুবে যাওয়া পাওনার পাহাড়
```

> **Cash Flow-এর জন্য এটাই সবচেয়ে দামি Setup। মাসে একবার Aged Receivable + Follow-up দেখলেই ব্যবসা নিশ্চিত।**

# Common Mistakes

❌ Invoice-এ Bank Details না দেওয়া — Payment আটকে থাকে।

❌ Terms ফাঁকা রাখা — ঝগড়ার সময় হাতে কিছু নেই।

❌ Payment Acquirer Test Mode-এ ভুলে যাওয়া — টাকা আসছে না কেন বোঝা যায় না।

❌ Sequence হাতে বদলানো — Audit-এ গ্যাপ ধরা পড়ে।

❌ Follow-up Setup না করা — পাওনা ডুবে যায় চুপচাপ।

❌ Customer-এ Payment Terms Default না দেওয়া — Due Date হারায়।

❌ Gateway Fee হিসাব না করা — লাভের হিসাব ভুল।

# Checklist

```
Invoice—

□  Layout-এ Logo + TIN + Bank Details + Terms

□  Default Terms লেখা

□  Email/Portal Send Test করেছি

□  Sequence ঠিক (হাতে ছোঁনি)

Payment—

□  Acquirer বাছাই + API Key বসানো

□  Test Mode-এ Test Payment সফল

□  Live Mode-এ স্যুইচ করেছি 🚨

□  Payment Terms Customer Profile-এ Default

Follow-up—

□  ৩টা Level বানানো (৩/১৫/৩০ দিন)

□  Test: পুরোনো Test Invoice-এ Follow-up দেখাচ্ছে

Final Test—

□  Invoice → Send → Pay → Paid পুরো Cycle ✅
```
