# PART A : Users & Access Rights

## কোথায়

```
Settings → Users & Companies → Users

→ User খোলো → Access Rights Tab
```

## Accounting-এর Role-গুলো — প্রতিটা কী পারে

### 1. Read-Only (Show Accounting Documents)

```
পারবে:    দেখতে — Invoice, Bill, Entry, Report

পারবে না: কিছু বানাতে বা বদলাতে
```

```
কাকে দেবে:

   Management, Auditor, Investor

   → যারা দেখবে, কিন্তু হাত দেবে না
```

### 2. Billing (Billing User)

```
পারবে:    Invoice, Bill, Credit Note, Payment বানাতে

পারবে না: Manual Entry, Reconciliation,

         Settings বদলাতে, Lock করতে
```

```
কাকে দেবে:

   Sales Team (Invoice বানাবে)

   Junior Accountant (Daily Data Entry)
```

### 3. Accountant (Full Accounting)

```
পারবে:    সব — Manual Entry, Bank Reconcile,

         Asset, Report, Adjustment
```

```
কাকে দেবে:

   Senior Accountant / Finance Manager
```

### 4. Administrator (Settings Access)

```
পারবে:    Accounting-এর সব + Configuration

         (COA, Tax, Journal বদলানো)
```

```
কাকে দেবে:

   শুধু তুমি (Team Lead) + ১ জন Backup

   → ২ জনের বেশি কখনো না
```

---

## Access দেওয়ার Golden Rules

```
Rule 1: Minimum Access

   → যা লাগবে, ঠিক ততটুকুই

   → "ওসাধারণ মানুষ, Admin দিয়ে দেই" — 🚫 কখনো না
```

```
Rule 2: এক কাজ, এক দায়িত্ব

   → যে Invoice বানায়, সে যেন Settings ছুঁতে না পারে

   → যে Settings পারে, সে দিনে ১০০টা Entry করে না
```

```
Rule 3: চাকরি ছাড়লে সেই দিনই Access বন্ধ

   → User Delete না → Access Rights সরাও / Deactivate করো

   → তার করা Entry-র History থেকে যায়
```

```
ভুল Access দিলে কী হয়:

   ❌ Junior ভুলে COA-র Account বদলে দিল → সব Report ভুল

   ❌ কেউ পুরোনো মাসের Entry বদলে দিল → Tax Report ফেল

   ❌ কেউ Bank Reconcile গুলিয়ে দিল → মাস শেষে আগুন
```

# PART B : Opening Balance

## আগে সিদ্ধান্ত নাও

```
নতুন Company?

   → Opening Balance লাগবে না

   → শুধু Owner Capital Entry: Dr Bank / Cr Capital

   → PART C-তে সরাসরি যাও
```

```
পুরোনো ব্যবসা, নতুন Odoo?

   → পুরোনো System/খাতার Closing Balance ঢোকাতে হবে

   → নিচের পুরো PART পড়ো
```

---

## কোন Date-এ ঢোকাবে?

```
নিয়ম: Fiscal Year-এর প্রথম দিনের আগের দিন

যেমন: Fiscal Year শুরু ১ জুলাই ২০২৬

   → Opening Entry-র Date: ৩০ জুন ২০২৬
```

```
কেন: নতুন বছরের প্রথম দিনে সব Balance Ready থাকে

     বছরের Report পরিষ্কার থাকে
```

---

## ধাপে ধাপে Opening Entry

```
Accounting → Accounting → Journal Entries → New
```

```
Journal: Miscellaneous

Date: ৩০/০৬/২০২৬ (Fiscal Year-এর আগের দিন)

Reference: "Opening Balance FY 2026-27"
```

## কী ঢোকাবে — পুরোনো Trial Balance থেকে

### Asset-গুলো (Debit)

```
Dr Bank                      50,000

Dr Cash                       5,000

Dr Accounts Receivable       10,000  ← Partner দিতে হবে!

Dr Inventory                 20,000

Dr Laptop/Fixed Asset        15,000
```

### Liability-গুলো (Credit)

```
    Cr Accounts Payable              15,000  ← Partner দিতে হবে!

    Cr Bank Loan                     25,000

    Cr VAT Payable                    3,000
```

### Equity (Credit — বাকিটা বলে দেয়)

```
    Cr Capital                       57,000
```

## শেষে Check

```
Debit Total  = 100,000

Credit Total = 100,000  ✓

না মিললে → পুরোনো Trial Balance আবার দেখো

কোনো Account বাদ পড়েছে
```

---

## 🚨 Opening Balance-এর ৩টা মারাত্মক ভুল

### ভুল 1 : Receivable/Payable-এ Partner না দেওয়া

```
করলে কী হয়:

   Entry তো হলো, কিন্তু Odoo জানে না

   কোন Customer-এর কত পাওনা

   → নতুন Payment মেলানো যায় না

   → Aged Report ফাঁকা

সমাধান: প্রতিটা Customer/Vendor-এর জন্য

   আলাদা Line, প্রতিটায় partner_id সহ
```

### ভুল 2 : Inventory দুইবার ঢোকানো

```
করলে কী হয়:

   Opening Entry-তেও Inventory দিলে,

   আবার Stock-এ Product-ও ঢোকালে

   → Inventory দ্বিগুণ দেখায়

সমাধান:

   Automated Inventory হলে Stock দিয়ে ঢোকাও,

   Opening Entry-তে Inventory বাদ দাও

   → একটাই রাস্তা বেছে নাও
```

### ভুল 3 : Opening আবার ঢোকানো

```
করলে কী হয়:

   একই Balance দুইবার Entry → সব দ্বিগুণ

সমাধান:

   Opening Entry Post করার পর

   Screenshot/PDF রেখে দাও

   → "হয়ে গেছে"-র প্রমাণ থাকলে কেউ আবার করবে না
```

   ✅ Test Sales দেখা যাচ্ছে
