# SECTION 1 : Taxes

## Default Taxes

```
কী:      নতুন Product বানালে কোন Tax নিজে বসবে

         → Sales Tax (যেমন: VAT 15%)

         → Purchase Tax (যেমন: VAT 15%)
```

```
করলে কী হয়:

   ✅ Invoice/Bill-এ Tax নিজে চলে আসে

   ✅ কেউ ভুলে Tax বাদ দিতে পারে না

না করলে কী হয়:

   ❌ প্রতিটা Invoice-এ হাতে Tax বসাতে হবে

   ❌ একদিন ভুলে যাবে → VAT কম গেল

      → সরকারের কাছে হিসাব মিলবে না
```

> **করবে: ✅ অবশ্যই।**

---

## Rounding Method

```
কী:      Tax হিসাবের দশমিক কীভাবে Round হবে

         → Round per Line (লাইন ধরে)

         → Round Globally (পুরো Invoice ধরে)
```

```
কোনটা দেবে:

   দেশের Tax Rule যা বলে তাই

   (বেশিরভাগ ক্ষেত্রে: Round Globally)
```

```
ভুল দিলে:

   Invoice Total-এ ১-২ পয়সা এদিক-সেদিক

   → Customer-এর System-এর সাথে মিলবে না

   → "আপনার Invoice আর আমার হিসাব তো মিলছে না"
```

---

## Cash Basis Tax

```
কী:      VAT কখন ধরবে—

         Invoice-এর সময় (Accrual — Default)

         নাকি Payment পাওয়ার সময় (Cash Basis)
```

```
চালু করলে:        টাকা না পেলে Tax-ও ধরা হবে না

না করলে (Default): Invoice-ই Tax-এর ঘটনা
```

```
কোনটা দেবে:

   তোমার দেশের Tax আইন যা বলে

   → নিশ্চিত না হলে চালু করো না

   → Tax Advisor-কে জিজ্ঞেস করো
```

> **⚠️ এটা এলোমেলো চালু করো না। পুরো Tax Report-এর Logic বদলে যায়।**

# SECTION 2 : Customer Invoices

## Invoice Terms (Default Terms & Conditions)

```
কী:      প্রতিটা Invoice-এর নিচে নিজে বসে যাওয়া লেখা

         যেমন: "Payment due within 30 days.

         Late payment will incur 2% monthly interest."
```

```
করলে:      Legally Protected থাকো, পাওনা আদায় সহজ

না করলে:   ঝগড়া হলে তোমার পক্ষে কোনো লেখা নেই
```

> **করবে: ✅। একবার লিখে দাও, সব Invoice-এ যাবে।**

---

## Invoice Online Payment / QR Code

```
কী:      Invoice-এ Payment Link / QR Code যাবে

         → Client Click করেই Pay করতে পারবে
```

```
করলে:      Payment ২× দ্রুত আসে (Statistics বলে)

না করলে:   Client-কে Bank Info আলাদা করে দিতে হয়

          → সে ভুলে যায় → Payment দেরি
```

```
শর্ত:     Payment Acquirable (যেমন Stripe/SSLCommerz)

         Setup করে থাকতে হবে
```

> **ছোট Company হলেও করো — Payment দ্রুত পাওয়াটাই Cash Flow।**

# SECTION 3 : Vendor Bills

## Bill Digitization (OCR)

```
কী:      Vendor-এর PDF/Scan Bill Upload করলে

         Odoo নিজে পড়ে লাইন ভরে দেয়
```

```
করলে:      Bill Entry-র ৮০% সময় বাঁচে

না করলে:   প্রতিটা Bill হাতে টাইপ

          → ধীর, ভুল-প্রবণ
```

```
মনে রাখবে:

   AI/OCR Credit লাগতে পারে (IAP)

   → প্রথমে কয়েকটা Bill দিয়ে Test করো
```

> **Vendor Bill মাসে ১০টার বেশি হলে ✅ চালু করো।**

# SECTION 4 : Bank & Cash

## Bank Synchronization

```
কী:      Bank-এর সাথে Direct Connect

# SECTION 5 : Default Accounts

## এখানে কী থাকে

```
Receivable Account   → Customer-এর পাওনা যাবে যেখানে

Payable Account      → Vendor-এর দেনা যাবে যেখানে
```

```
কী কাজে:

   নতুন Customer/Vendor বানালে

   এই Account-গুলো নিজে বসে যায়
```

```
ভুল থাকলে কী হয়:

   ❌ সব Invoice-এর Receivable ভুল Account-এ

   ❌ Aged Report ভুল

   ❌ Balance Sheet ভুল

   ❌ ঠিক করতে গিয়ে শত শত Entry বদলাতে হবে
```

> **🚨 Localization-এ যেটা এসেছে সেটাই সাধারণত ঠিক। না বুঝে হাত দিও না। তবে একবার খুলে দেখে নাও কোন Account বসে আছে।**

# SECTION 6 : Advanced Features (চালু করবে নাকি?)

## Analytic Accounting

```
কী:      Project/Department-ভিত্তিক খরচ Track

         ("কী খরচ" না, "কার জন্য খরচ")
```

```
চালু করলে:

   ✅ প্রতিটা Entry-তে Project Tag দেওয়া যায়

   ✅ Project-ভিত্তিক Profit Report পাও
```

```
কখন চালু করবে:

   একাধিক Project/Client থাকলে (Software Company = ✅)

   একটাই Product/Service হলে → লাগবে না
```

---

## Budget Management

```
কী:      Plan vs Actual (কত ভাবছিলে, কত হলো)
```

```
কখন চালু করবে:

   Management Budget নিয়ে কাজ করে → ✅

   ছোট Team, মৌখিক Budget → এখন না, পরে
```

```
মনে রাখবে: Analytic Accounting ছাড়া কাজ করে না
```

---

## Asset Management / Deferred Revenue

```
কী:      Fixed Asset-এর Auto Depreciation

         + অগ্রিম Income-এর Auto Release
```

```
কখন চালু করবে:

   Laptop/Vehicle/Machine আছে → ✅

   Annual Subscription/Contract বিক্রি করো → ✅

(বিস্তারিত Module 11 ও Advanced Note-এ)
```

---

## Multi-Currencies

```
কী:      Dollar/Euro-তে Invoice, Taka-তে হিসাব
```

```
কখন চালু করবে:

   বিদেশি Client/Vendor থাকলে → ✅ অবশ্যই

   শুধু দেশের ভিতরে কাজ → না
```

```
চালু করলে কী হয়:

# SECTION 7 : Lock Dates (মাস শেষে ব্যবহার করবে)

```
Tax Lock Date        → Tax Report Final হওয়া Period-এ হাত বন্ধ

Sales Lock Date      → পুরোনো Invoice বন্ধ

Purchase Lock Date   → পুরোনো Bill বন্ধ

Global Lock (All)    → সব বন্ধ

Hard Lock            → কেউই কিছু পারবে না
```

```
Setup-এর সময় কী করবে:

   → এখন কিছু দিও না

   → প্রথম মাস শেষে প্রথম Lock Date দেবে

   (বিস্তারিত Module 13: Fiscal Year-এ)
```

```
নিয়ম:

   মাস শেষ → Report Final → Tax Paid → Lock

   এই ক্রম কখনো উল্টাবে না
```

# Common Mistakes

❌ সব Switch চালু করে ফেলা — "যত ফিচার তত ভালো" না।

❌ Default Accounts নিজে বদলে দেওয়া।

❌ Cash Basis না বুঝে চালু করা।

❌ Invoice Terms ফাঁকা রাখা।

❌ Lock Date Setup-এর দিনেই দেওয়া — নিজেরই Entry আটকে যাবে।

❌ Multi-Currency চালু করে Rate Update না করা।
