## নতুন Account বানানো — প্রতিটা Field

### 1. Code

```
কী:      Account-এর নম্বর (যেমন: 100100, 400500)
```

```
কেন দরকার:

   হাজার Account-এর মধ্যে Code দিয়ে Sort/Search হয়

   Report-এ Code অনুযায়ী সাজে
```

```
Convention (Localization মেনে চলো):

   1xxxxx → Asset

   2xxxxx → Liability

   3xxxxx → Equity

   4xxxxx → Income

   5xxxxx/6xxxxx → Expense
```

```
ভুল করলে: Report-এ Account এলোমেলো জায়গায় বসে
```

---

### 2. Account Name

```
কী:      মানুষের পড়ার নাম (যেমন: "Software Sales")
```

```
Rule: এমন নাম দাও যাতে ৬ মাস পরেও বোঝো কীসের Account

❌ "Sales1", "New Account", "Test"

✅ "Software License Sales", "AWS Hosting Expense"
```

---

### 3. Type 🚨 (সবচেয়ে গুরুত্বপূর্ণ Field)

```
কী:      এই Account কোন Category-র

কেন:     Type-ই ঠিক করে—

         ১. Balance Sheet-এ যাবে, নাকি P&L-এ

         ২. বছর শেষে শূন্য হবে, নাকি বয়ে যাবে

         ৩. Report-এর কোন লাইনে বসবে
```

| Type | কোথায় যায় | বছর শেষে |
|---|---|---|
| Current Asset | Balance Sheet | বয়ে যায় |
| Fixed Asset | Balance Sheet | বয়ে যায় |
| Current Liability | Balance Sheet | বয়ে যায় |
| Non-current Liability | Balance Sheet | বয়ে যায় |
| Equity | Balance Sheet | বয়ে যায় |
| Income | P&L | শূন্য হয় |
| Expense / COGS / Depreciation | P&L | শূন্য হয় |

```
ভুল Type দিলে কী হয়:

   ❌ Sales-কে Asset করলে → Sales Balance Sheet-এ যাবে,

      P&L-এ Income দেখাবে না → মালিক ভাববে লাভ নেই

   ❌ Expense-কে Asset করলে → লাভ ফুলিয়ে দেখাবে

      → ভুল Tax → জরিমানা
```

> **নিয়ম: নতুন Account বানানোর আগে নিজেকে জিজ্ঞেস করো—"এটা কি আমার সম্পদ, দেনা, মালিকের, আয়, নাকি খরচ?" উত্তরটাই Type।**

# PART B : Taxes Setup

## কোথায়

```
Accounting → Configuration → Taxes
```

## প্রতিটা Field

### 1. Tax Name

```
কী:      Invoice-এ যা দেখাবে (যেমন: "VAT 15%")

Rule:   Customer-ও বুঝবে এমন নাম
```

---

### 2. Tax Type (Tax Scope)

```
Sales     → Invoice-এ ব্যবহার হবে (Output VAT)

Purchase  → Bill-এ ব্যবহার হবে (Input VAT)

None      → অন্য Tax-এর ভিতরে অংশ হিসেবে
```

```
ভুল দিলে:

   Sales Tax Invoice-এ আসবে না

   → হাতে Tax বসাতে হবে প্রতিবার
```

---

### 3. Tax Computation

```
Percentage of Price        → 15% of Amount (সাধারণ VAT)

Fixed Amount               → যেমন: ৫০ টাকা প্রতি পণ্যে

Percentage of Price (Included)

   → দামের ভিতরেই Tax ধরা আছে

   → দোকানে "VAT সহ ১১৫ টাকা" এরকম

Group of Taxes             → কয়েকটা Tax একসাথে
```

```
⚠️ "Included" আর সাধারণ গুলিয়ো না:

   Included না হলে: ১০০০ + ১৫০ = ১১৫০

   Included হলে:    ১১৫০-র ভিতরে ১৫০ Tax

   ভুল Select করলে পুরো দাম বদলে যাবে
```

---

### 4. Amount

```
কী:      15 মানে 15%

সহজ, কিন্তু 15.0 লিখে Save ঠিকমতো হয়েছে দেখো
```

---

### 5. Tax Account (Distribution/Invoice Repartition) 🚨

```
কী:      এই Tax-এর টাকা কোন COA Account-এ জমা হবে
```

```
Sales Tax হলে:

   → VAT Payable (Output Tax Account)

Purchase Tax হলে:

   → VAT Receivable (Input Tax Account)
```

```
না দিলে / ভুল দিলে কী হয়:

   ❌ Invoice Post-এ Tax-এর লাইন ভুল Account-এ যায়

   ❌ Tax Report ফাঁকা বা ভুল আসে

   ❌ মাস শেষে সরকারকে কত দেবে — জানা যায় না
```

> **এটাই Tax Setup-এর সবচেয়ে বড় ভুলের জায়গা। Tax বানানোর পর একটা Test Invoice Post করে Journal Entry-তে Tax Line কোন Account-এ গেছে—দেখে নাও।**

---

### 6. Tax Grids / Report Line

```
কী:      এই Tax Tax Report-এর কোন লাইনে বসবে
```

```
করলে:    Tax Report নিজে নিজে ভরে যায়

না করলে: মাস শেষে হাতে হিসাব → ভুলের সম্ভাবনা
```

---

### 7. Label on Invoices

```
কী:      Invoice PDF-এ Tax-এর পাশে কী লেখা থাকবে

যেমন:   "VAT 15%" বা "Value Added Tax (15%)"
```

# PART C : Fiscal Position (Advanced, তবে জেনে রাখো)

```
কী:      Customer/Vendor অনুযায়ী Tax বদলে দেওয়ার Rule
```

```
কখন লাগে:

   বিদেশি Customer → VAT 0% (Export)

   দেশি Customer   → VAT 15%

   → একটা Rule বসিয়ে দিলে Invoice-এ নিজে বদলে যায়
```

```
না বসালে: প্রতিবার হাতে Tax বদলাতে হবে → একদিন ভুল হবেই
```

```
কোথায়: Accounting → Configuration → Fiscal Positions
```

# Common Mistakes

❌ Account Type ভুল দেওয়া — COA-র সবচেয়ে মারাত্মক ভুল।

❌ Receivable/Payable-এ Reconciliation বন্ধ রাখা।

❌ Tax Account ফাঁকা রাখা — Tax Report ভেঙে যায়।

❌ Tax Included/Excluded গুলিয়ে ফেলা — দামই বদলে যায়।

❌ Account Delete করা — Archive করতে হয়।

❌ প্রতিটা ছোট খরচের জন্য আলাদা Account — COA অগোছালো হয়।

❌ Fiscal Position না বানিয়ে বিদেশি Client-এ হাতে Tax বদলানো।

# Checklist

```
COA—

□  Localization-এর সব Account ঘেঁটে দেখেছি

□  অদরকারি Account Archive করেছি

□  নিজের Income Account-গুলো বানিয়েছি (সঠিক Type)

□  নিজের Expense Account-গুলো বানিয়েছি (সঠিক Type)

□  Receivable/Payable-এ Reconciliation চালু Check

□  Code Convention মেনেছি (1=Asset, 4=Income...)

Taxes—

□  Sales VAT: Type=sale, Amount ঠিক, Tax Account দেওয়া

□  Purchase VAT: Type=purchase, Tax Account দেওয়া

□  Test Invoice-এ Tax Line সঠিক Account-এ গেছে দেখেছি

□  Tax Grid/Report Line বসে আছে

□  বিদেশি Client থাকলে Fiscal Position বানিয়েছি
```
