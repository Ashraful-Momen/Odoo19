# Setup Step 1 : Apps & Modules — কোনটা Odoo Default, কোনটা OCA

**Series: Odoo 19 ERP Perfect Setup (Step 1 of 11) — File 0.3**

> **ভুল Module Install করলে System ভারী হয়, Data গুলায়, Update-এ ভাঙে। সঠিক Module Install করলে ৮০% কাজ Automatic। এই Note বলবে— কোনটা লাগবেই, কোনটা লাগবে না, কোনটা OCA থেকে আনবে।**

# Chapter 1 : আগে বুঝো — Module-এর ৩টা জগৎ

```
১. Odoo Default (Community)

   → Odoo-র সাথেই আসে, Free

   → Apps Menu-তে Search করে Install
```

```
২. Odoo Enterprise

   → Paid License লাগে

   → কিছু Feature শুধু Enterprise-এ

   (যেমন: Full Accounting Report UI, Bank Sync)
```

```
৩. OCA (Odoo Community Association)

   → Community-র বানানো Free Module

   → GitHub থেকে নামাতে হয়

   → Default-এ যা নেই, তার ৮০% এখানে আছে
```

> **মনে রাখবে— আগে Default খোঁজো। না পেলে OCA। OCA-তেও না থাকলে Custom বানাও। এই ক্রম মেনে চললে System কখনো ভারী হবে না।**

# Chapter 2 : বাধ্যতামূলক Module (এগুলো ছাড়া কিছুই না)

## 1. Accounting (`account`)

```
কোথায়: Apps → Search "Accounting" → Install
```

```
কী পাবে:

   COA, Journal, Entry, Invoice, Bill,

   Payment, Report — পুরো Accounting
```

```
না করলে: অবশ্যই কিছুই হবে না। এটাই Core।
```

> **⚠️ Enterprise License থাকলে "Accounting" Full UI পাবে। Community-তে "Invoicing" নামে হালকা Version আসে — তবু Core Database একই (`account.move`)।**

---

## 2. Contacts (`contacts`)

```
কী: Customer / Vendor (res.partner) Master
```

```
সাধারণত Accounting-এর সাথে নিজেই আসে

না থাকলে আলাদা করে Install করো
```

```
না করলে: Invoice-এ Customer Select করতে পারবে না।
```

---

## 3. Sales (`sale`) — Software Company-র জন্য

```
কী পাবে: Quotation → Sales Order → Invoice (Auto)
```

```
কেন করবে:

   Client-কে আগে Quotation পাঠাও

   → Accept করলে এক Click-এ Invoice

   → Invoice-এ হাতে কিছু লিখতে হয় না
```

```
না করলে কী হয়:

   প্রতিবার হাতে Invoice বানাতে হবে

   → সময় নষ্ট, ভুলের সম্ভাবনা বেশি
```

---

## 4. Purchase (`purchase`)

```
কী পাবে: Purchase Order → Vendor Bill (Auto) → 3-Way Matching
```

```
কেন করবে:

   Vendor-কে Order Track হয়

   → মাল আসলে Bill নিজে তৈরি হয়

   → ভুল/বাড়তি Bill ধরা পড়ে
```

```
না করলে: হাতে Bill দিতে হবে, Matching-এর সুবিধা থাকবে না।
```

---

## 5. Inventory (`stock`) — যদি পণ্য বিক্রি করো

```
কী পাবে: Stock Tracking + Automatic COGS Entry

   (Module 10: Inventory Accounting মনে আছে?)
```

```
কেন করবে:

   পণ্য ঢুকলেই Entry, বের হলেই COGS

   → Profit নিজে বের হয়
```

```
না করলে:

   Inventory হিসাব হাতে করতে হবে

   → COGS ভুল, Profit ভুল
```

```
⚠️ শুধু Service বিক্রি করলে (যেমন Software/Consulting)

   এই Module লাগবে না — Install করো না।

   অদরকারি Module = ভারী System।
```

# Chapter 3 : পরে লাগবে (প্রথম দিনে না)

```
Expenses       → Employee-দের খরচের Claim (বড় Team হলে)

Documents      → Bill/Invoice-এর File Archive

Spreadsheet    → Report-এর উপর Custom Analysis

Project        → Project-ভিত্তিক Cost (Analytic-এর সাথে জোড়া)
```

# Chapter 4 : OCA Module — কী, কেন, কীভাবে

## OCA কী?

```
Odoo Community Association

→ পুরো দুনিয়ার Developer মিলে বানায়

→ Free, Open Source

→ github.com/OCA
```

---

## কীভাবে Install করবে?

```
১. GitHub থেকে Module Download / Clone

২. Server-এর addons path-এ রাখো

৩. odoo.conf-এ path যোগ করো

৪. Apps → Update Apps List

৫. Search করে Install
```

> **⚠️ সবসময় Check করো Module-টা Odoo 19-এর জন্য আছে কিনা। পুরোনো Version-এর Module জোর করে বসালে System ভাঙবে।**

---

## দরকারি OCA Module-গুলো (Accounting-এর জন্য)

| OCA Module | কী দেয় | কখন লাগবে |
|---|---|---|
| `account_financial_report` | Enterprise-মতো সুন্দর Trial Balance, General Ledger, Aged Report | **Community Version-এ হলে প্রায় মাস্ট** |
| `mis_builder` | Custom Financial Report বানানো (কোনো Code ছাড়া) | Management-কে Custom Report দিতে চাইলে |
| `account_reconcile_oca` | ভালো Bank Reconciliation UI | Community-তে Default Reconcile দুর্বল লাগলে |
| `account_move_line_report` | Move Line-এর Ready Report | Audit-এর সময় |
| `date_range` | অনেক OCA Report Module-এর Dependency | ওপরেরগুলোর সাথে নিজে আসে |

---

## OCA ব্যবহারের Rule

```
করলে কী হয়:

   ✅ Enterprise Feature Free-তে পাও

   ✅ বড় Community-র Test-করা Code

না বুঝে করলে কী হয়:

   ❌ Version Mismatch-এ System ভাঙে

   ❌ Update করতে গিয়ে ঝামেলা

   ❌ Module-এর উপর নির্ভর হয়ে যাও
```

> **Golden Rule: OCA Module যত কম, তত ভালো। শুধু যেটা সত্যিই দরকার। আমার Recommendation: Community Version-এ `account_financial_report` + `mis_builder` — এই দুইটা যথেষ্ট।**

# Common Mistakes

❌ প্রথম দিনেই ৩০টা Module Install করা — System ভারী, নিজেই হারিয়ে যাবে।

❌ Invoicing আর Accounting দুইটা Install করা — একটাই লাগে।

❌ Service Company-তে Inventory Install করা — অদরকারী।

❌ OCA Module Version না দেখে বসানো।

❌ Enterprise Feature আশা করে Community-তে বসে থাকা — আগে জেনে নাও কোনটা কোথায় পাওয়া যায়।

❌ Default-এ Feature আছে, তাও OCA বসানো — দুইটা একই কাজ করতে গিয়ে Conflict।

# Checklist

```
□  Contacts Install

□  Accounting Install (দেশ সঠিকভাবে Select করেছি)

□  Purchase Install (Bill Automation লাগবে)

□  Inventory — পণ্য থাকলেই, নাহলে Skip

□  OCA: account_financial_report (Community হলে)

□  OCA: mis_builder (Custom Report লাগলে)

□  অদরকারি কিছু Install করিনি

□  Apps List Update করে সব সবুজ (কোনো Error নেই)
```
