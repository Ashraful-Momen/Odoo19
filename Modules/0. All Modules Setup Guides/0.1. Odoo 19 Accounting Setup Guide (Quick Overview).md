# Step 1 : Accounting App Install

```
Odoo Login

↓

Apps Menu

↓

Search: "Invoicing" বা "Accounting"

↓

Install
```

দুইটা App আছে—

```
Invoicing   → হালকা Version (Invoice/Bill/Payment)

Accounting  → Full Version (Report, Asset, Budget, Lock Date সব)
```

> **Team Lead হিসেবে সরাসরি "Accounting" Install করো। Invoicing দিয়ে শুরু করে পরে মাথা গরম করো না।**

Install হলে সাথে সাথে Odoo জিজ্ঞেস করবে—

```
তোমার Company কোন দেশের?
```

কারণ দেশ অনুযায়ী COA আর Tax আসবে (পরের Step-এ)।

# Step 5 : Chart of Accounts (COA)

## Localization — Odoo নিজে দেয়

Accounting Install-এর সময় দেশ Select করলে

Odoo নিজেই সেই দেশের Standard COA বসিয়ে দেয়—

```
Bangladesh / US / UK — দেশভেদে আলাদা

শত শত Ready Account

সঠিক Type সহ
```

## দেখতে যাবে

```
Accounting

↓

Configuration

↓

Chart of Accounts
```

## তোমার কাজ

```
১. Ready Account-গুলো একবার ঘেঁটে দেখো

২. তোমার Business-এর বিশেষ Account যোগ করো

   যেমন: "Software Sales", "Hosting Income"

৩. অদরকারি Account Archive করে দাও

   (Delete না — Archive)
```

> **⚠️ নতুন Account বানানোর সময় সবচেয়ে গুরুত্বপূর্ণ হলো সঠিক Type Select করা। Type ভুল = Report ভুল।**

# Step 6 : Taxes Setup

```
Accounting

↓

Configuration

↓

Taxes
```

## Check করো

Localization-এর সাথে Default Tax এসেছে—

```
VAT 15% (Sales)

VAT 15% (Purchase)
```

## তোমার কাজ

```
১. Default Sales Tax ঠিক আছে কিনা দেখো

২. Default Purchase Tax ঠিক আছে কিনা দেখো

   (Accounting → Configuration → Settings → Taxes)
```

প্রতিটা Tax-এর ভিতরে Check—

```
Tax Type     → sale / purchase

Amount       → 15%

Tax Account  → কোন COA Account-এ যাবে

              (VAT Payable / VAT Receivable)
```

> **⚠️ Tax Account Setup না থাকলে Invoice Post করলে Tax-এর Entry ভুল জায়গায় যাবে বা Error দেবে।**

# Step 10 : Users ও Access Rights

## কে কী পারবে — ঠিক করে দাও

```
Settings

↓

Users & Companies

↓

Users

↓

User খোলো → Access Rights Tab
```

## Accounting-এর Role-গুলো

```
Read-Only        → শুধু দেখতে পারবে

Billing          → Invoice/Bill বানাতে পারবে

Accountant       → Entry, Reconcile, Report — সব

Administrator    → Setup + সবকিছু
```

## Real Life Rule

```
Sales Team   → Billing (Invoice বানাবে)

Junior Acc   → Billing + Bank

Senior Acc   → Accountant (Full)

তুমি (Lead)  → Administrator
```

> **⚠️ সবাইকে Administrator দিও না। একজন ভুল Entry দিলে সবার Report ভুল।**

# Step 11 : Opening Balance (যদি পুরোনো ব্যবসা হয়)

## নতুন Company হলে

এই Step Skip করো। Owner Capital-এর Entry দিলেই শুরু—

```
Dr Bank / Cr Capital
```

## পুরোনো ব্যবসা থেকে আসলে

পুরোনো খাতার Closing Balance ঢোকাও—

```
Accounting

↓

Accounting

↓

Journal Entries

↓

New

Journal: Miscellaneous

Date: Fiscal Year-এর প্রথম দিন
```

Example Entry—

```
Dr Bank                    50,000

Dr Inventory               20,000

Dr Accounts Receivable     10,000   (Partner দিতে ভুলো না!)

    Cr Accounts Payable            15,000  (Partner সহ)

    Cr Loan                        25,000

    Cr Capital                     40,000
```

```
Debit = Credit মিলতে হবে ✓
```

> **⚠️ Receivable/Payable লাইনে Partner না দিলে পরে Customer-Vendor-এর পাওনা-দেনা Track হবে না।**

# Interview Questions

### 1. Odoo Install-এর পর Accounting-এর প্রথম কাজ কী?

**উত্তর:** Company Setup—বিশেষ করে Currency, Country আর VAT Number। কারণ Currency পরে বদলানো কঠিন, আর Country অনুযায়ী COA/Tax আসে।

---

### 2. Localization কী?

**উত্তর:** দেশ অনুযায়ী Ready-made COA, Tax আর Journal—যা Accounting App Install-এর সময় দেশ Select করলে Odoo নিজে বসিয়ে দেয়।

---

### 3. Invoicing আর Accounting App-এর পার্থক্য?

**উত্তর:** Invoicing হালকা Version (Invoice/Bill/Payment), Accounting হলো Full Version—Report, Asset, Budget, Lock Date সব সহ।

---

### 4. পুরোনো ব্যবসার Data কীভাবে Odoo-তে আনবে?

**উত্তর:** Opening Balance Entry—Fiscal Year-এর প্রথম দিনের Date-এ, Miscellaneous Journal-এ, সব Account-এর Balance সহ (Debit = Credit মিলিয়ে)।

---

### 5. Bank Journal-এর ৩টা গুরুত্বপূর্ণ Account কী?

**উত্তর:** Bank Account (Default), Outstanding Receipts, Outstanding Payments—এগুলো ঠিক থাকলে Bank Reconciliation Automatic চলে।

---

# Common Mistakes (Setup-এ)

❌ Currency ভুল দেওয়া—পরে সব Entry ভুল মুদ্রায়।

❌ Fiscal Year Setup না করা—Report ভুল Period-ে আসে।

❌ Tax Account Setup না করে Invoice Post করা।

❌ সবাইকে Administrator Access দেওয়া।

❌ Opening Balance-এ Partner না দেওয়া—পাওনা-দেনা Track হারায়।

❌ Default COA না দেখে নতুন Account বানানো—Duplicate হয়।

❌ Test না করে Live যাওয়া—প্রথম Invoice-এই ভুল ধরা পড়ে।

❌ Bank Account-এর Outstanding Accounts গুলিয়ে ফেলা।
