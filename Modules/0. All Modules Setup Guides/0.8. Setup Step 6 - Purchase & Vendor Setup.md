# Setup Step 6 : Purchase & Vendor Setup

**Series: Odoo 19 ERP Perfect Setup (Step 6 of 11) — File 0.7.4**

> **কেনার দিকে Setup ভুল হলে — Vendor যা চায় তাই Bill দেয়, তুমি চেক করার উপায়ই পাও না। এই File-এ PO → Receive → Bill-এর পুরো Chain, আর 3-Way Matching যা তোমাকে ভুল Payment থেকে বাঁচাবে।**

---

# Chapter 1 : Purchase Flow আগে বুঝো

```
Purchase Order (PO) তৈরি

   ↓ (Vendor-কে পাঠালে)

Vendor মাল পাঠাল

   ↓

Receipt (মাল Receive — Inventory-তে Auto)

   ↓

Vendor Bill এলো

   ↓

3-Way Match: PO = Receipt = Bill?

   ↓ (মিললে)

Payment → Paid ✅
```

> **মূল কথা: Bill তখনই Pay করবে, যখন তিনটা কাগজ মিলবে। Setup-এর কাজ — এই Matching Automatic করা।**

## SECTION : Orders

### 1. Purchase Agreement (Blanket Order)

```
কী:      Vendor-এর সাথে বছরের Contract —

         "বছরে ৫০০টা Laptop নেব, এই দামে"

         তারপর মাসে মাসে ওই Contract থেকে Order
```

```
করলে কী হয়:

   ✅ প্রতিবার দরকষাকষি লাগে না

   ✅ Vendor দাম বাড়াতে পারে না

কখন:    একই Vendor থেকে নিয়মিত কেনা হয়

না করলে: প্রতি PO-তে নতুন দাম — Track কঠিন
```

### 2. Purchase Order Approval

```
কী:      নির্দিষ্ট Amount-এর বেশির PO

         Manager Approve না করলে Confirm হয় না
```

```
করলে কী হয়:

   ✅ Junior ভুলে $50,000-এর Order দিতে পারবে না

   ✅ বড় খরচে মালিকের অনুমতি নিশ্চিত
```

```
না করলে কী হয়:

   ❌ যে-কেউ যেকোনো Amount-এর Order দিতে পারে

   ❌ ঘুষ/ভুল Order ধরা পড়ে মাস শেষে
```

```
কোথায়: Settings → Orders → Purchase Order Approval

   → Minimum Amount ঠিক করো (যেমন: $5,000)
```

> **Team Lead হিসেবে এটা ✅ অবশ্যই চালু করো। একটা Limit সবকিছু বদলে দেয়।**

## SECTION : Invoicing

### 4. Bill Control Policy 🚨

```
কী:      Bill কোন Quantity ধরে বানবে?
```

| Policy | মানে | কখন |
|---|---|---|
| Ordered Quantities | PO-তে যা আছে তাই Bill | Service/Advance কেনা |
| Received Quantities | যতটা এসেছে ততটাই Bill | পণ্য ✅ |

```
Received Quantities করলে কী হয়:

   ✅ ১০টার PO, ৮টা এলো → Bill-এ ৮টাই আসবে

   ✅ বাকি ২টা আসলে পরে আলাদা Bill

   ✅ না আসা মালের টাকা কখনো যায় না
```

```
Ordered করলে:

   মাল আসার আগেই পুরো Bill — পণ্যের জন্য বিপদ
```

> **পণ্য কিনলে: Received Quantities। এটাই 3-Way Matching-এর ভিত্তি।**

### 5. Vendor Bill Digitization (OCR)

না করলে: প্রতিটা Bill হাতে টাইপ → ভুলের সুযোগ

# Chapter 3 : 3-Way Matching — বুঝেই চালু করো

## কী

```
তিনটা কাগজ মেলানো—

   ১. Purchase Order  → কী চেয়েছিলে

   ২. Receipt         → কী পেয়েছো

   ৩. Vendor Bill     → কী ধরেছে Vendor
```

## কেন

```
মিললে:      নিশ্চিত হয়ে Pay করো

না মিললে:   "অর্ডার ১০টা, এসেছে ৮টা, Bill ১০টার"

            → আটকে দাও, Vendor-কে জিজ্ঞেস করো
```

## Odoo-তে কীভাবে কাজ করে

```
Bill Control = Received Quantities রাখলে

→ Bill তৈরি হয় Receipt থেকে

→ তিনটা নিজে মিলে যায়

→ মিল না থাকলে Quantity-তেই ধরা পড়ে
```

```
করলে কী হয়:

   ✅ বাড়তি Bill কখনো Pay হয় না

   ✅ Fraud/ভুল প্রায় অসম্ভব

না করলে:

   ❌ Vendor যা লিখে দিল তাই Pay

   ❌ বছর শেষে হিসাব মেলাতে গিয়ে আগুন
```

# Chapter 4 : Vendor Master Setup

```
Purchase → Vendors → New
```

## গুরুত্বপূর্ণ Field

### 1. Name + Address + Tax ID

```
কেন: Bill-এ Vendor-এর তথ্য যায়

   Tax ID ছাড়া Input VAT Adjust করা যায় না
```

### 2. Payment Terms

```
Vendor-কে কত দিনে Pay করবে (যেমন: Net 30)

করলে:   Bill-এ Due Date নিজে আসে

        → Aged Payable কাজ করে

        → কাকে কবে দিতে হবে Dashboard-এ দেখো
```

### 3. Payable Account

```
Localization-এ Default বসে আছে

→ শুধু Check করো, বদলিও না
```

### 4. Bank Details

```
Vendor-এর Bank Account রেখে দাও

করলে:   Payment-এর সময় ভুল Account-এ টাকা যায় না
```

# Chapter 5 : Vendor-এর সাথে কেনা পণ্য যুক্ত করা

```
Product → Purchase Tab

   → Vendor Add

   → দাম, Minimum Quantity, Delivery Lead Time
```

## Lead Time কেন গুরুত্বপূর্ণ?

```
কী:   Order দিলে কত দিনে মাল আসে

করলে কী হয়:

   ✅ Replenishment সঠিক দিনে Order দেয়

      (Stock ফুরানোর ৫ দিন আগে, Lead Time মিলিয়ে)

না দিলে: Stock ফুরিয়ে যাওয়ার পরে Order যায়

        → মাল আসতে আসতে Customer চলে গেল
```

# Common Mistakes

❌ Bill Control = Ordered রেখে পণ্য কেনা — না আসা মালেরও টাকা যায়।

❌ PO Approval ছাড়া চালানো — বড় ভুল Order আটকানো যায় না।

❌ Vendor Pricelist না দেওয়া — প্রতিবার ভিন্ন দাম।

❌ Lead Time ফাঁকা — Replenishment ভুল দিনে Order দেয়।

❌ Vendor-এর Tax ID না নেওয়া — Input VAT ফেরত পাবে না।

❌ Payment Terms না দেওয়া — কার Bill কবে Due, হিসাব নেই।

❌ Receipt না করে Bill Post করা — Stock আর Account মিলে না।
