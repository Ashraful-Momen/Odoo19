# Chapter 1 : Sales Flow আগে বুঝো

```
Quotation তৈরি

   ↓ (Client-কে Email/Portal-এ পাঠালে)

Client Accept করল

   ↓ (Confirm)

Sales Order

   ↓

Delivery (পণ্য হলে — Inventory থেকে Auto)

   ↓

Invoice (Auto Create)

   ↓

Payment → Paid ✅
```

> **Setup-এর লক্ষ্য একটাই — এই Flow-এ তোমার হাত যত কম লাগে, তত ভালো।**

## SECTION : Quotation & Orders

### 1. Online Signature / Online Payment

```
কী:      Client Quotation-এ Click করে

         Signature / Advance Payment দিতে পারে
```

```
করলে কী হয়:

   ✅ Client নিজেই Confirm করে → Order নিজে তৈরি

   ✅ Advance নিজে আসে → Cash Flow দ্রুত

না করলে:

   Email → Print → Sign → Scan → ফেরত পাঠাবে

   → ৩ দিনের কাজ ৩ মিনিটে হওয়ার কথা ছিল
```

```
শর্ত: Online Payment-এর জন্য Payment Acquirer লাগবে

     (File 0.7.5-এ Setup শেখানো আছে)
```

---

### 2. Quotation Templates

```
কী:      Ready-made Quotation Format

         যেমন: "Annual Software Contract Template"
```

```
করলে কী হয়:

   ✅ একই ধরনের Deal বারবার → Template Select → শেষ

   ✅ দাম/Term ভুল হয় না

না করলে:

   প্রতিবার সব Line হাতে লেখা

   → একবার দাম ভুল লিখলে Client ধরে বসে
```

```
কোথায়: Sales → Configuration → Quotation Templates

কখন বানাবে: একই Package ৩+ বার বিক্রি হলে
```

### 3. Default Quotation Validity

```
কী:      Quotation কত দিন Valid থাকবে (যেমন: ৩০ দিন)
```

```
করলে:   পুরোনো Quotation নিজে Expire হয়

        → পুরোনো দামে Order আটকে যায়

না করলে: ২ বছর আগের দামে আজ Order দিলে করার উপায় নেই
```

### 4. Sale Order Warnings / Locking

```
কী:      Confirm হওয়া Order বদলানো আটকানো

করলে:   Delivery চলছে, কেউ Order বদলে দিল না

না করলে: Order বদলে গেল, আগেরটা Ship হয়ে গেল

        → Customer-এর সাথে ঝগড়া
```

## SECTION : Pricing

### 5. Pricelists 🚨

```
কী:      Customer-ভেদে আলাদা দাম

         যেমন—

         Retail Customer  → $100

         Corporate Client → $85

         Distributor      → $70
```

```
চালু করতে:

   Settings → Pricing → Pricelists

   (দুইটা Mode—

     Multiple Prices per Product  ← সহজ, বেশিরভাগের জন্য

     Advanced Price Rules          ← Formula-ভিত্তিক)
```

```
করলে কী হয়:

   ✅ Customer Select করলেই তার দাম নিজে আসে

   ✅ Sales Team-কে দাম মনে রাখতে হয় না

না করলে:

   প্রতিবার হাতে দাম বদলানো

   → একদিন Corporate-কে Retail দামে Invoice গেল

   → আরেকদিন Retail-কে Corporate দামে (লোকসান!)
```

```
কোথায় বানাবে:

   Sales → Products → Pricelists

   তারপর Customer-এর Profile-এ Default Pricelist বসাও
```

# Chapter 3 : Product Setup (Sales-এর দিক থেকে)

```
Sales → Products → Products → New
```

## গুরুত্বপূর্ণ Field

### 1. Product Type

```
Storable   → পণ্য (Stock যাবে-আসবে)

Service    → Service (Stock নেই)

Consumable → কেনা-খাওয়া জিনিস (Track দরকার নেই)
```

### 2. Invoicing Policy 🚨 (Software Company-র জন্য Critical)

```
কী:      Invoice কখন বানবে?
```

| Policy | Invoice কখন | কখন ব্যবহার করবে |
|---|---|---|
| Ordered Quantities | Order Confirm হলেই পুরো | Service/License — কাজ শুরুর আগে Bill |
| Delivered Quantities | Delivery যতটা হয়েছে ততটা | পণ্য — যতটা দিলে ততটার Bill |

```
ভুল দিলে কী হয়:

   পণ্যে Ordered দিলে → মাল যাওয়ার আগেই পুরো Bill

   Service-এ Delivered দিলে → কিছুই Deliver হয় না,

   Invoice বানানোই যায় না 😅
```

```
Rule:

   Software/Service → Ordered Quantities

   পণ্য            → Delivered Quantities
```

### 3. Sales Price + Customer Taxes

```
Sales Price → তোমার List Price

Tax         → Default Sales Tax নিজে বসবে (Step 9-এ Set করেছো)

করলে:      Invoice-এ দাম+VAT নিজে আসে

না করলে:   প্রতিবার হাতে দাম লেখা
```

### 4. Income Account

```
কোন COA Account-এ এই পণ্যের Sales যাবে

যেমন: "Software License Sales"

করলে:   P&L-এ দেখবে কোন পণ্যে কত আয়

না করলে: সব এক Account-এ গাদা → বিশ্লেষণ শেষ
```

# Common Mistakes

❌ Invoicing Policy ভুল দেওয়া — পুরো Billing Flow ভেঙে যায়।

❌ Pricelist না বানিয়ে হাতে দাম বদলানো — একদিন লোকসানে বিক্রি হয়েই যাবে।

❌ Quotation Validity না দেওয়া — পুরোনো দামে Order এসে যায়।

❌ Product-এ Income Account ফাঁকা — সব Sales এক গাদায়।

❌ সবাইকে Margin দেখতে দেওয়া — Client-এর সামনে Cost ফাঁস।

❌ Template না বানিয়ে একই Proposal বারবার টাইপ করা।

❌ Service Product-কে Storable বানানো।

□  Sales Price + Tax বসে আছে

□  Income Account দেওয়া

People—

□  প্রধান Customer-এর Profile-এ Default Pricelist
