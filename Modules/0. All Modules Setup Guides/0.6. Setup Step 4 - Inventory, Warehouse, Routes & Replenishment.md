# Chapter 1 : Concept Map — ৫টা জিনিস আগে বুঝো

```
Warehouse      → কোন গুদামে (ঢাকা? CTG?)

Location       → গুদামের ভিতরে কোথায় (Shelf A? Rack 2?)

Operation Type → কী ঘটছে (Receive? Deliver? Internal Move?)

Route          → পণ্য কী পথে চলে (কিনে→গুদাম→বেচে? সরাসরি?)

Replenishment  → Stock ফুরালে নিজে কেনার Rule
```

পুরো Flow—

```
Vendor → Receive → Stock (Location-এ জমা) → Deliver → Customer

                ↑                         ↑
        Replenishment              Route ঠিক করে
        (ফুরালে Auto Order)         (কোন পথে যাবে)
```

# Chapter 2 : Warehouse Setup

## কোথায়

```
Inventory → Configuration → Warehouses
```

## Default-এ একটা থাকে

```
Install করলেই একটা Warehouse থাকে (তোমার Company-র নামে)

→ ছোট ব্যবসা হলে এটাই যথেষ্ট
```

## প্রতিটা Field

### 1. Warehouse Name + Short Name

```
Short Name (যেমন: WH, CTG)

→ Stock Location-এর নামে ব্যবহার হয়: WH/Stock
```

### 2. Company / Branch

```
কোন Company বা Branch-এর Warehouse

(Branch Setup মনে আছে? File 0.7.1)

→ ভুল দিলে ভুল Branch-এর Stock দেখাবে
```

### 3. Address

```
গুদামের ঠিকানা

→ Dropship/Delivery Document-এ লাগে
```

## একাধিক Warehouse কখন?

```
✅ একাধিক Branch/শহরে Stock থাকলে

✅ Main Stock আর Showroom Stock আলাদা রাখতে চাইলে

❌ একটাই গুদামে শুধু Shelf আলাদা করতে চাইলে

   → ওটা Warehouse না, Location (নিচে দেখো)
```

```
একাধিক Warehouse চালু করতে:

Inventory → Configuration → Settings

→ Storage Categories / Multi-Warehouse চালু
```

# Chapter 3 : Location Setup

## কী জিনিস

```
Warehouse = গুদামের বাড়ি

Location  = বাড়ির ভিতরের ঘর

যেমন:

   WH/Stock              → মূল Stock

   WH/Stock/Shelf A      → A তাক

   WH/Stock/Shelf B      → B তাক

   WH/Input              → মাল আসার জায়গা

   WH/Output             → মাল যাওয়ার জায়গা
```

## চালু করতে

```
Inventory → Configuration → Settings

→ Storage Locations চালু
```

```
করলে কী হয়:

   ✅ কোন পণ্য কোন তাকে — Track হয়

   ✅ "মাল আছে কিন্তু খুঁজে পাচ্ছি না" — শেষ

না করলে:

   পুরো গুদাম = একটা Location

   → ঠিক আছে, ছোট গুদামে লাগে না
```

## Location-এর গুরুত্বপূর্ণ Type

```
Internal Location   → তোমার গুদামের ভিতরের

Vendor Location     → Vendor-এর জগৎ (Virtual)

Customer Location   → Customer-এর জগৎ (Virtual)

Inventory Loss      → নষ্ট/হারানো মালের জায়গা
```

> **Virtual মানে: Receive মানে Vendor Location → তোমার Stock। এই Concept বুঝলে সব Move বোঝা যায়।**

# Chapter 4 : Operation Types & Routes

## Operation Type কী?

```
কোন ধরনের Move—

   Receipts        (মাল আসছে)

   Delivery Orders (মাল যাচ্ছে)

   Internal Transfers (ভিতরে সরছে)
```

```
কোথায়: Inventory Dashboard-এ প্রতিটার Card

→ প্রতিটার নিজের Sequence, নিজের Flow আছে
```

## Route কী? (সবচেয়ে গুরুত্বপূর্ণ Concept)

```
পণ্য কোন পথে চলবে — সেটাই Route
```

### সাধারণ Route-গুলো

```
১. Buy (কেনা)

   Vendor → তোমার Stock

২. Deliver (বিক্রি)

   তোমার Stock → Customer

৩. Buy + Deliver একসাথে = চাইন
```

### বিশেষ Route

```
Dropship:

   Vendor → সরাসরি Customer

   → তুমি মাঝখানে, তোমার গুদামে মাল আসেই না

   কখন: Stock রাখো না, Order পেলে কিনে পাঠাও
```

```
Resupply from another Warehouse:

   CTG-এ Stock নেই → ঢাকা Warehouse থেকে আসবে
```

## Route কোথায় Set করবে?

```
দুই জায়গায়—

১. Product Category-তে (সব পণ্যের Default)

২. Product-এ (নির্দিষ্ট পণ্যের)
```

```
ভুল Route দিলে কী হয়:

   ❌ Purchase করলে মাল ভুল জায়গায় যায়

   ❌ Sales করলে Stock থেকে কাটে না

   ❌ COGS Entry-ও ভুল হয় (Accounting-এ আঘাত)
```

# Chapter 5 : ১-Step বনাম ২/৩-Step Receive & Delivery

```
Inventory → Configuration → Settings

→ Warehouse Section
```

## Receive-এর Option

```
১ Step:  Vendor → Stock (সরাসরি)

   ছোট গুদাম ✅ — মাল এলো, ঢুকালে, শেষ
```

```
২ Step:  Vendor → Input → Stock

   আগে Input-এ জমা, QC Check, তারপর Stock-এ

   মাঝারি গুদাম
```

```
৩ Step:  Vendor → Input → Quality Control → Stock

   বড় গুদাম, যেখানে মাল পরীক্ষা করে নেওয়া হয়
```

## Delivery-তেও একই

```
১ Step:  Stock → Customer (সরাসরি) ✅ ছোট ব্যবসা

২ Step:  Stock → Picking → Output → Customer

৩ Step:  Pick → Pack → Ship
```

```
কোনটা দেবে?

   ছোট Team (২-৫ জন) → ১ Step

   গুদামে আলাদা আলাদা লোক Receive/Pack করে → ২-৩ Step

ভুল দিলে:

   বেশি Step দিলে → ছোট Team-এ অদরকারি ঝামেলা

   কম Step দিলে → বড় গুদামে কে কী করল Track হারায়
```

# Chapter 6 : Replenishment (Stock ফুরালে Auto Order)

## Real Life সমস্যা

```
মাউস প্যাড বিক্রি করো।

Stock-এ ৫টা আছে। হঠাৎ ২০টার Order এলো।

→ তুমি জানতেও পারলে না Stock ফুরিয়েছে

→ Customer-কে "নেই" বললে → সে চলে গেল প্রতিযোগীর কাছে
```

## সমাধান — দুইটা রাস্তা

### রাস্তা ১ : Reordering Rules (Min-Max)

```
Inventory → Products → Reordering Rules

→ নতুন Rule:

   Product      → Mouse Pad

   Min Quantity → 10

   Max Quantity → 50
```

```
করলে কী হয়:

   ✅ Stock ১০-এর নিচে নামলেই

     Odoo নিজে Purchase Draft বানায় (Max পর্যন্ত)

   ✅ কখনো Stock-Out হয় না
```

### রাস্তা ২ : MTO (Make to Order)

```
Order আসলে তখনই কেনা/বানানো

→ Product-এ Route: Buy + MTO

কখন: দামি/কম চলা পণ্য, Stock রাখা অযথা খরচ
```

```
কোনটা কখন:

   নিয়মিত চলা পণ্য → Reordering Rule

   দামি/রেয়ার পণ্য  → MTO
```

# Chapter 7 : Product Setup (Inventory-এর জন্য)

```
Inventory → Products → Products → New
```

## গুরুত্বপূর্ণ Field

### Product Type 🚨

```
Storable Product   → Stock Track হবে (পণ্য)

Consumable         → Stock Track হবে না (অফিস সরঞ্জাম)

Service            → Stock-ই নেই (Consulting)
```

```
ভুল দিলে:

   Service-কে Storable করলে → নেগেটিভ Stock-এর জট

   পণ্যকে Consumable করলে → Stock জানা যাবে না → COGS ভুল
```

### Product Category 🚨 (Accounting-এর সাথে জোড়া)

```
Category-তেই বসে—

   Costing Method (FIFO/AVCO/Standard)

   Inventory Valuation (Automated/Manual)

   Stock Valuation Account

   Stock Input/Output Account
```

```
করলে কী হয়:

   ✅ প্রতিটা Stock Move-এ Auto Journal Entry

   ✅ COGS নিজে বের হয় (Module 10 মনে আছে?)

ভুল দিলে:

   ❌ Stock Move হলো, Accounting Entry হলো না

   ❌ মাস শেষে COGS হাতে বসাতে হবে
```

### Unit of Measure

```
কী এককে মাপবে — Unit, Kg, Box, Dozen

ভুল দিলে: ১ Box কিনে ১ Unit ধরা → সব হিসাব গুলে যায়
```

# Chapter 8 : Opening Stock ঢোকানো

```
Inventory → Operations → Inventory Adjustments

→ প্রতিটা পণ্যের Actual Quantity বসাও

→ Apply

✅ Check: Stock Valuation Account-ে Entry গেছে কিনা
```

```
⚠️ মনে আছে File 0.11-এর ভুল ২?

   Opening Stock Stock দিয়ে ঢোকালে

   → Opening Journal Entry-তে Inventory বাদ

   → একটাই রাস্তা, দুইবার না
```

# Common Mistakes

❌ Service Company-তে Inventory চালু করা।

❌ প্রতি Shelf-এর জন্য আলাদা Warehouse — Location লাগে, Warehouse না।

❌ ছোট Team-এ ৩-Step Receive — অদরকারি ঝামেলা।

❌ Product Category-তে Valuation Account না দেওয়া — Entry হয় না।

❌ Reordering Rule ছাড়া Stock চালানো — Stock-Out হয়েও টের পাও না।

❌ Opening Stock দুই জায়গায় (Entry + Adjustment) ঢোকানো।

❌ Route ভুল দেওয়া — মাল এলো কিন্তু Stock বাড়ল না।
