# Chapter 2 : প্রতিটা Table এক নজরে

## account_account (COA)

```
কী: সব Account-এর Master List

গুরুত্বপূর্ণ Field:

   code          → 100100

   name          → Cash

   account_type  → asset_current, income, expense...

   reconcile     → True/False

   company_ids
```

---

## account_journal

```
কী: Transaction-এর Category

Field:

   name          → Sales

   code          → SAJ

   type          → sale / purchase / bank / cash / general

   default_account_id  (Bank/Cash Journal-এ)

   company_id
```

---

## account_move (সবচেয়ে গুরুত্বপূর্ণ)

```
কী: Journal Entry Header

   Invoice, Bill, Payment, Manual Entry—

   সবই এখানে

Field:

   name           → INV/2026/0005

   journal_id

   date

   state          → draft / posted / cancel

   move_type      → out_invoice / in_bill
                    out_refund / in_refund / entry

   partner_id

   line_ids       → One2many → move lines

   amount_total

   amount_residual → কত বাকি

   payment_state  → not_paid / partial / paid

   company_id
```

---

## account_move_line

```
কী: Entry-র প্রতিটা Debit/Credit লাইন

Field:

   move_id

   account_id

   partner_id

   name            → Label

   debit

   credit

   balance         → debit − credit

   date_maturity   → Due Date

   reconciled

   full_reconcile_id
```

---

## account_payment

```
কী: Payment-এর Document

Field:

   payment_type   → inbound / outbound

   partner_id

   amount

   journal_id

   date

   move_id        → Payment-এর Entry
```

> **মনে রাখবে— Payment-ও শেষ পর্যন্ত একটা `account.move`-ই তৈরি করে।**

---

## account_tax

```
কী: Tax Master

Field:

   name           → VAT 15%

   type_tax_use   → sale / purchase

   amount         → 15.0

   amount_type    → percent / fixed
```

---

## account_partial_reconcile / account_full_reconcile

```
কী: Invoice ↔ Payment Match-এর Record

partial  → কিছু অংশ Match

full     → পুরোটা Match (Invoice Paid)
```

# Chapter 3 : একটা Invoice-এ Database-এ কী ঘটে?

Customer Invoice $5,000 + 15% VAT Post করলে—

```
account_move-এ ১টা Row

   move_type = out_invoice

   state = posted
```

```
account_move_line-এ ৩টা Row

   1. Receivable    Debit   5,750   (partner = Customer)

   2. Sales         Credit  5,000

   3. VAT Payable   Credit    750   (tax line)
```

---

## তারপর Payment $5,750 হলে

```
account_payment-এ ১টা Row

account_move-এ আরো ১টা Row (Payment-এর Entry)
```

```
account_move_line-এ ২টা Row

   1. Bank          Debit   5,750

   2. Receivable    Credit  5,750   (partner = Customer)
```

---

## তারপর Reconcile

```
Invoice-এর Receivable Line

        +

Payment-এর Receivable Line

        ↓

account_full_reconcile-এ ১টা Row

        ↓

Invoice-এর payment_state → paid

amount_residual → 0
```

# Chapter 4 : Developer হিসেবে Code Flow

## Manual Entry Code দিয়ে বানানো

```python
move = env['account.move'].create({
    'journal_id': misc_journal.id,
    'date': fields.Date.today(),
    'line_ids': [
        (0, 0, {
            'account_id': bank_account.id,
            'debit': 10000,
        }),
        (0, 0, {
            'account_id': capital_account.id,
            'credit': 10000,
        }),
    ],
})

move.action_post()
```

> **একই Structure-এ Invoice, Bill—সব বানানো যায়। শুধু `move_type` বদলাও।**

---

## Balance বের করা

```
কোনো Account-এর Balance =

(debit − credit) এর Sum

যেখানে account_id = ওই Account
```

# Chapter 5 : যে ভুলগুলো Developer করে

❌ `state = 'posted'` Filter ভুলে যাওয়া—Draft-ও হিসাবে ঢুকে যায়।

❌ `company_id` Filter না দেওয়া।

❌ Invoice আর Manual Entry গুলিয়ে ফেলা—`move_type` Check করো।

❌ হাতে `account_move_line` Edit করা—Balance গুলিয়ে যায়। সবসময় Move-এর মাধ্যমে।

❌ Payment-কে শুধু `account.payment` ভাবা—আসল Entry `account.move`-এ।

# Interview Questions

### 1. Odoo-তে Invoice কোন Table-এ থাকে?

**উত্তর:** `account_move`-এ, `move_type = 'out_invoice'` হিসেবে।

---

### 2. একটা Invoice Post করলে কয়টা Table-এ Data যায়?

**উত্তর:** মূলত দুইটায়—`account_move` (Header) আর `account_move_line` (Receivable, Revenue, Tax লাইন)।

---

### 3. Invoice "Paid" হয় কীভাবে?

**উত্তর:** Payment-এর Receivable Line আর Invoice-এর Receivable Line Reconcile হলে (`account_full_reconcile`)—তখন `amount_residual = 0` আর `payment_state = 'paid'`।

---

### 4. কোনো Customer-এর মোট পাওনা কীভাবে বের করবে?

**উত্তর:** ওই Partner-এর সব Posted Receivable Move Line-এর Balance Sum—যেগুলো এখনো Reconcile হয়নি।

---

### 5. Report-গুলো কোন Table থেকে আসে?

**উত্তর:** প্রায় সবই `account_move_line` থেকে—Account, Date, Partner দিয়ে Group/Sum করে।

# Cheat Sheet

```
Screen-এ যা দেখো    Database-ে যা হয়
─────────────────────────────────────────
Journal          →  account_journal
COA              →  account_account
Invoice/Bill     →  account_move (+lines)
Manual Entry     →  account_move (entry)
Payment          →  account_payment + account_move
Reconcile        →  partial/full_reconcile
Tax              →  account_tax + tax lines
Report           →  move_line-এর Group/Sum
```
