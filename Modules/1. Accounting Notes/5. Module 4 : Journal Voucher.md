# Voucher কী?

Accounting-এ প্রতিটা Entry-র পেছনে একটা প্রমাণ থাকা উচিত।

```
Receipt        → টাকা পেলাম

Payment Voucher → টাকা দিলাম

Bill           → কেনার প্রমাণ

Invoice        → বিক্রির প্রমাণ

Debit Note     → দেনা বাড়ানোর নোট

Credit Note    → দেনা কমানোর নোট
```

এই প্রমাণপত্র দেখেই Accountant Journal Entry করে।

# Journal Voucher বনাম Journal Entry

| Journal Voucher              | Journal Entry                  |
| ---------------------------- | ------------------------------ |
| প্রমাণপত্র (Document)         | খাতায় লেখা (Record)            |
| আগে হয়                      | পরে হয়                         |
| Receipt, Bill, Memo          | Debit / Credit লাইন             |
| Audit-এর প্রমাণ              | Ledger-এর ভিত্তি               |

Flow—

```
Business Event

↓

Voucher (প্রমাণ)

↓

Journal Entry (লেখা)

↓

Ledger

↓

Report
```

```

# Chapter 3 : Manual Entry-র Real Examples

## Example 1 : Opening Balance

নতুন Company। Owner Bank-এ $50,000 দিল।

```
Debit    Bank              $50,000

Credit   Owner Capital     $50,000
```

---

## Example 2 : Accrued Salary

মাস শেষ হলো।

কর্মচারীর Salary $2,000 এখনো দেওয়া হয়নি।

কিন্তু খরচ তো এই মাসেরই।

```
Debit    Salary Expense    $2,000

Credit   Salary Payable    $2,000
```

পরের মাসে Salary দিলে—

```
Debit    Salary Payable    $2,000

Credit   Bank              $2,000
```

---

## Example 3 : Prepaid Rent

১ বছরের Rent অগ্রিম দিলে $12,000।

পুরোটা এই মাসের খরচ না।

```
Debit    Prepaid Rent (Asset)  $12,000

Credit   Bank                  $12,000
```

প্রতি মাসে $1,000 করে খরচ ধরবে—

```
Debit    Rent Expense      $1,000

Credit   Prepaid Rent      $1,000
```

---

## Example 4 : Depreciation

Laptop $2,000। প্রতি মাসে $50 করে মূল্য কমছে।

```
Debit    Depreciation Expense        $50

Credit   Accumulated Depreciation    $50
```

(বিস্তারিত Module 11 : Fixed Assets-এ)

---

## Example 5 : ভুল Entry ঠিক করা

ভুল করে Salary-র জায়গায় Rent-এ Entry হয়ে গেছে $500।

Correction Entry—

```
Debit    Salary Expense    $500

Credit   Rent Expense      $500
```

# Adjustment Entry

## কেন দরকার?

ধরো December মাসের Electricity Bill $300

জানুয়ারিতে আসবে।

কিন্তু খরচটা December-এর।

```

# Business Story

তোমার Software Company।

মাস শেষে Accountant দেখল—

```
১. Developer-দের Salary $5,000 দেওয়া হয়নি

২. Office-এর Rent ৬ মাসের Advance দেওয়া $6,000

৩. Server (Asset) প্রতি মাসে $200 হারে Depreciate হচ্ছে

```

চারটা Adjustment Entry—

```
১. Debit  Salary Expense        $5,000

   Credit Salary Payable        $5,000
```

```
২. Debit  Prepaid Rent          $6,000

   Credit Bank                  $6,000

   (আগে দেওয়া থাকলে প্রতি মাসে Rent Expense $1,000)
```

```
৩. Debit  Depreciation Expense       $200

   Credit Accumulated Depreciation   $200
```

```
৪. Debit  Bank                       $2,000

   Credit Unearned Revenue (Liability) $2,000
```

> **এই চারটা Entry ছাড়া Profit & Loss কখনোই সঠিক হবে না।**

# Interview Questions

### 1. Voucher কী?

**উত্তর:** Transaction-এর প্রমাণপত্র—Receipt, Bill, Invoice, Memo—যা দেখে Journal Entry করা হয়।

---

### 2. Journal Voucher আর Journal Entry-র পার্থক্য?

**উত্তর:** Voucher হলো প্রমাণ (Document), Entry হলো সেই প্রমাণ দেখে খাতায় করা লেখা (Debit/Credit Record)। Odoo-তে Voucher হিসেবে Move-এর সাথে File Attach করা হয়।

---

### 3. Manual Journal Entry কখন করবে?

**উত্তর:** যখন Transaction-এর জন্য Odoo-তে কোনো Automatic Document (Invoice/Bill/Payment) নেই—যেমন Opening Balance, Depreciation, Accrual, Correction।

---

### 4. Adjustment Entry কী?

**উত্তর:** মাস/বছর শেষে করা Entry যাতে Expense ও Income সঠিক Period-এ বসে—যেমন Accrued Salary, Prepaid Rent, Depreciation।

---

### 5. Manual Entry কোন Journal-ে করবে?

**উত্তর:** Miscellaneous (General) Journal-এ।

---

### 6. Prepaid Expense-এর Entry কী?

**উত্তর:** অগ্রিম দেওয়ার সময়—Debit Prepaid Expense (Asset), Credit Bank। প্রতি মাসে—Debit Expense, Credit Prepaid Expense।

---

### 7. Odoo-তে Manual আর Automatic Entry-র পার্থক্য?

**উত্তর:** Database-এ কোনো পার্থক্য নেই—দুটোই `account.move`। পার্থক্য শুধু সৃষ্টির উৎসে—মানুষ নাকি System।

---

# Common Mistakes

❌ Sales Journal-এ Manual Entry করা।

❌ Adjustment Entry না দিয়ে Report বের করা—Profit ভুল আসে।

❌ Prepaid Rent পুরোটা এক মাসে Expense ধরা।

❌ Correction-এর জন্য Posted Entry Delete করতে চেষ্টা করা—নতুন Correction Entry দিতে হয়।

❌ Manual Entry-তে Reference/কারণ না লেখা—Audit-এ ধরা খাবে।

❌ Attachment না দেওয়া—প্রমাণ ছাড়া Entry।

# Module 4 শেষ করার পর তোমার যা বোঝা উচিত

* Voucher হলো Transaction-এর প্রমাণ; Entry হলো তার Record।
* Odoo-তে আলাদা Voucher নেই—Move-এর Attachment-ই Voucher।
* Invoice, Bill, Payment Odoo নিজে Entry বানায়।
* Opening, Depreciation, Accrual, Correction—এগুলো Manual Entry।
* Manual Entry সবসময় Miscellaneous Journal-এ।
* Adjustment Entry ছাড়া Financial Report কখনো নির্ভুল না।
