# 1. Deferred Revenue (অগ্রিম আয়)

## Story

Customer ১ বছরের Support Contract কিনল—$12,000, আগেই দিয়ে দিল।

পুরো $12,000 কি এই মাসের Income?

না।

```
Service তো ১২ মাস ধরে দেবে

→ Income-ও ১২ মাসে ভাগ হবে
```

## Entry

টাকা পেলে—

```
Debit    Bank                  $12,000

Credit   Unearned Revenue      $12,000   (Liability)
```

প্রতি মাসে—

```
Debit    Unearned Revenue      $1,000

Credit   Service Revenue       $1,000
```

> **টাকা আগে, Income পরে—এটাই Deferred Revenue।**

## Odoo-তে

```
Invoice Line-এ Deferred Revenue Model লাগালে

Odoo প্রতি মাসে Automatic Entry দেয়

(Assets-এর Depreciation-এর মতোই)
```

# 2. Deferred Expense (অগ্রিম খরচ)

## Story

১ বছরের Insurance $6,000 অগ্রিম দিলে।

পুরোটা এই মাসের খরচ না।

## Entry

দেওয়ার সময়—

```
Debit    Prepaid Insurance     $6,000   (Asset)

Credit   Bank                  $6,000
```

প্রতি মাসে—

```
Debit    Insurance Expense     $500

Credit   Prepaid Insurance     $500
```

> **টাকা আগে, খরচ পরে—Deferred Revenue-র উল্টোটা।**

---

# 3. Analytic Accounting (Cost Center)

## Story

তোমার Company-তে ৩টা Project চলছে।

মালিক জিজ্ঞেস করল—

```
"কোন Project-এ লাভ কত?"
```

সাধারণ Account বলতে পারবে না—সে শুধু বলে মোট Salary কত।

## সমাধান

প্রতিটা Expense/Income-এর সাথে একটা Tag—

```
Analytic Account

   ├── Project A

   ├── Project B

   └── Project C
```

Salary Entry করার সময়—

```
Debit    Salary Expense    $3,000

         Analytic: Project A

Credit   Bank              $3,000
```

## Report

```
Accounting → Reporting → Analytic Report

→ Project-ভিত্তিক Income/Expense/Profit
```

> **Financial Account বলে "কী খরচ", Analytic Account বলে "কার জন্য খরচ"।**

## Database

```
account_analytic_account

account_move_line-এ analytic_distribution
```

# 4. Budget

## Story

বছরের শুরুতে ঠিক করলে—

```
Marketing-এ খরচ হবে $10,000

Salary-তে হবে $50,000
```

বছর চলাকালীন দেখবে—

```
Plan বনাম Actual কেমন চলছে
```

## Odoo-তে

```
Analytic Account-এর উপর Budget বসে

Analytic Entry জমা হতে থাকে

↓

Budget Report দেখায়—

   Planned  vs  Actual  vs  বাকি
```

# 5. Multi Currency

## Story

তোমার Company-র হিসাব Taka-তে।

কিন্তু এক Client-কে Dollar-এ Invoice করতে হলো—$1,000।

সেদিনের Rate: $1 = ৳110।

## Entry

```
Debit    Receivable    $1,000  (= ৳110,000)

Credit   Sales         $1,000  (= ৳110,000)
```

Odoo দুটোই রাখে—

```
amount_currency  → $1,000

balance          → ৳110,000
```

## Odoo Setup

```
Settings → Currencies চালু

Currency Rate নিয়মিত Update

Invoice-এ Currency Select
```

# 6. Exchange Difference (Rate বদলের হিসাব)

## Story (আগেরটারই পর্ব)

Invoice-এর দিন Rate ছিল ৳110।

Customer ৩০ দিন পর দিল—তখন Rate ৳115।

Customer দিল $1,000 = এখন ৳115,000।

তাহলে—

```
তোমার বাড়তি পেলে ৳5,000

এটা বিক্রির লাভ না

Rate-এর লাভ (Exchange Gain)
```

## Entry

```
Debit    Bank                 ৳115,000

Credit   Receivable           ৳110,000

Credit   Exchange Gain        ৳5,000
```

Rate কমে গেলে হতো—

```
Debit Exchange Loss
```

## Odoo-তে

```
Payment-এর সময় Odoo নিজে

Exchange Difference Entry বানায়

(Automatic)
```

> **Invoice-এর দিনের Rate আর Payment-এর দিনের Rate—পার্থক্যটাই Gain/Loss।**


# Interview Questions

### 1. Deferred Revenue কী?

**উত্তর:** টাকা আগে পেয়েছো কিন্তু Service পরে দেবে—তাই Income সময়ের সাথে ভাগ করে ধরা, আগ পর্যন্ত Liability (Unearned Revenue) হিসেবে।

---

### 2. Analytic Account আর Financial Account-এর পার্থক্য?

**উত্তর:** Financial Account বলে "কী খরচ" (Salary, Rent), Analytic Account বলে "কার জন্য/কোন Project-এ খরচ"।

---

### 3. Exchange Gain কখন হয়?

**উত্তর:** Invoice আর Payment-এর মাঝে Currency Rate তোমার অনুকূলে বদলালে।

---

### 4. Prepaid Expense কি Asset?

**উত্তর:** হ্যাঁ—টাকা দিয়েছো কিন্তু Service এখনো পাওনি, তাই এটা তোমার সম্পদ; সময়ের সাথে Expense-এ যায়।

---

# Cheat Sheet

```
টাকা আগে, Income পরে  → Deferred Revenue (Liability)

টাকা আগে, খরচ পরে     → Deferred Expense / Prepaid (Asset)

কার জন্য খরচ           → Analytic Account

Plan vs Actual        → Budget

বিদেশি মুদ্রা          → Multi Currency

Rate বদল               → Exchange Gain / Loss
```
