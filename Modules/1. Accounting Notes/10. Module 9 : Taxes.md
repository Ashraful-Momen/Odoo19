আজ আমরা শিখব **VAT ও Tax-এর পুরো হিসাব**।

> **তুমি VAT-এর মালিক না। তুমি শুধু সরকারের হয়ে VAT সংগ্রহ করো। এই এক লাইন বুঝলে Tax-এর সব Accounting ক্লিয়ার।**

# Chapter 1 : Real Life Story

ভাবো তুমি একটা রেস্টুরেন্টে খেলে।

বিল এলো—

```
খাবার          ১,০০০

VAT 15%          ১৫০

─────────────────────

মোট            ১,১৫০
```

তুমি ১,১৫০ টাকা দিলে।

এখন প্রশ্ন—

**এই ১৫০ টাকা কি রেস্টুরেন্টের?**

না।

রেস্টুরেন্ট শুধু সরকারের হয়ে তোমার কাছ থেকে তুলেছে।

মাস শেষে এই ১৫০ টাকা সরকারকে দিতে হবে।

তাই রেস্টুরেন্টের খাতায়—

```
খাবারের ১,০০০ → আমার Income

VAT ১৫০      → সরকারের টাকা (আমার কাছে জমা)
```

এই "সরকারের টাকা আমার কাছে জমা"-টাই হলো—

# Chapter 2 : VAT-এর পুরো চক্র

তোমার Company একই সাথে দুই কাজ করে—

```
বিক্রির সময় VAT তোলে (Output VAT)

কেনার সময় VAT দেয়  (Input VAT)
```

---

## Output VAT (বিক্রিতে তোলা)

```
Customer-এর কাছ থেকে তুললে

→ সরকারকে দিতে হবে

→ তোমার Liability
```

## Input VAT (কেনায় দেওয়া)

```
Vendor-কে দিলে

→ সরকারের কাছ থেকে ফেরত পাবে / Adjust হবে

→ তোমার Asset
```

---

## মাস শেষে হিসাব

```
Output VAT (তোলা)      $750

Input VAT (দেওয়া)     $150

─────────────────────────

সরকারকে দিতে হবে       $600
```

```
Output > Input → পার্থক্য সরকারকে দাও

Input > Output → পার্থক্য ফেরত পাবে / পরে Adjust
```

> **VAT মানে— তোলা আর দেওয়ার পার্থক্য সরকারকে দেওয়া।**

# Chapter 3 : Journal Entry দিয়ে বুঝি

## Sales Invoice ($5,000 + 15% VAT)

```

Credit   Software Sales         $5,000

Credit   VAT Payable            $750     ← Output VAT
```

---

## Vendor Bill ($1,000 + 15% VAT)

```
Debit    Hosting Expense        $1,000

Debit    VAT Receivable         $150     ← Input VAT

Credit   Accounts Payable       $1,150
```

---

## মাস শেষে সরকারকে Payment

```
Debit    VAT Payable            $600

Credit   Bank                   $600
```

(বাস্তবে Output আর Input Adjust করে Net দেওয়া হয়—Odoo-র Tax Report-ই এই হিসাব দেয়।)

# Chapter 4 : Withholding Tax (WHT)

## Real Life Story

তুমি একটা Freelancer-কে কাজ দিলে—$1,000।

সরকার বলছে—

```
"পুরো $1,000 দিও না।

10% ($100) কেটে সরকারকে দাও।

Freelancer-কে দাও $900।"
```

মানে তুমি সরকারের হয়ে Tax **আটকে (Withhold)** রাখছো।

---

## Entry

Freelancer-এর Bill এলো—

```
Debit    Consulting Expense       $1,000

Credit   Accounts Payable         $900

Credit   Withholding Tax Payable  $100
```

সরকারকে দিলে—

```
Debit    Withholding Tax Payable  $100

Credit   Bank                     $100
```

---

## VAT বনাম WHT

| VAT                        | Withholding Tax              |
| -------------------------- | ---------------------------- |
| বিক্রির/কেনার উপর           | Income-এর উপর                |
| Customer দেয়, তুমি জমা রাখো | তুমি আটকে রাখো, সরকারকে দাও |
| দামের সাথে যোগ হয়           | Payment থেকে কাটা হয়         |

# Interview Questions

### 1. VAT কী?

**উত্তর:** Value Added Tax—বিক্রির উপর সরকারের Tax, যা Seller সরকারের হয়ে Customer-এর কাছ থেকে সংগ্রহ করে।

---

### 2. Output VAT আর Input VAT-এর পার্থক্য?

**উত্তর:** বিক্রিতে তোলা VAT হলো Output (Liability), কেনায় দেওয়া VAT হলো Input (Asset)। মাস শেষে পার্থক্য সরকারকে দিতে হয়।

---

### 3. VAT Payable কোন ধরনের Account?

**উত্তর:** Current Liability—কারণ এই টাকা সরকারের, তোমার কাছে জমা মাত্র।

---

### 4. Withholding Tax কী?

**উত্তর:** Payment করার সময় একটা অংশ আটকে রেখে সরাসরি সরকারকে দেওয়া—যেমন Freelancer-এর Payment থেকে 10% কাটা।

---

### 5. Sales-এর Invoice-এ $1,000 + 15% VAT হলে Entry কী?

**উত্তর:** Debit Receivable $1,150; Credit Sales $1,000; Credit VAT Payable $150।

---

### 6. Input VAT Output-এর চেয়ে বেশি হলে?

**উত্তর:** পার্থক্য সরকারের কাছে পাওনা থাকে—পরের মাসে Adjust হয় বা Refund নেওয়া যায়।

---

# Common Mistakes

❌ VAT-কে নিজের Income ভাবা—এটা সরকারের টাকা।

❌ Sales আর Purchase একই Tax ব্যবহার করা।

❌ Tax Account Setup না করে Invoice Post করা।

❌ VAT-সহ Amount-কে Sales ধরা—Sales হলো VAT-বাদে Amount।

❌ Tax Report না দেখে আন্দাজে সরকারকে Payment করা।

❌ WHT না কেটে পুরো Payment করে ফেলা—পরে সরকারকে নিজের পকেট থেকে দিতে হবে।

# Module 9 শেষ করার পর তোমার যা বোঝা উচিত

* VAT তোমার না—তুমি সরকারের হয়ে তুলো।
* Output VAT = Liability (Payable), Input VAT = Asset (Receivable)।
* মাস শেষে Output − Input = সরকারকে দেওয়া।
* Withholding Tax মানে Payment থেকে কেটে সরকারকে দেওয়া।
* Tax Configuration ঠিক থাকলে Odoo নিজে Tax Line বানায়।
* Tax Report-ই মাস শেষের VAT হিসাব।
