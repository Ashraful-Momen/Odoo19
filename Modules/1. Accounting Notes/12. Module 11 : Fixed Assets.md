যে জিনিস—

```

```

Example—

```

```

| Inventory             | Fixed Asset            |
| --------------------- | ---------------------- |

# Chapter 3 : Depreciation-এর Accounting Logic

## কেনার সময়

Laptop কিনলে $2,000—

```
Debit    Laptop (Fixed Asset)   $2,000

Credit   Bank                   $2,000
```

> **Expense হয়নি! Asset কিনেছো।**

---

## প্রতি মাসে

Laptop ৪ বছর (৪৮ মাস) চলবে ধরো।

```
$2,000 ÷ 48 মাস = ~$42 প্রতি মাসে
```

প্রতি মাসের Entry—

```
Debit    Depreciation Expense        $42

Credit   Accumulated Depreciation    $42
```

---

## Accumulated Depreciation কী?

```
লগ্নির পর থেকে

মোট কত মূল্য কমল

তার জমানো হিসাব
```

এটা Asset-এর "Negative" Account।

Balance Sheet-এ দেখায়—

```
Laptop (কেনা দাম)              $2,000

Accumulated Depreciation       -$504   (১২ মাস পরে)

─────────────────────────────────────

Book Value (আজকের মূল্য)      $1,496
```

> **কেন আলাদা Account? কেনার দামটা হারিয়ে যায় না, দুটোই দেখা যায়।**

---

## মাস শেষে Effect

```
Profit & Loss-এ:

Depreciation Expense $42  → Profit কমে
```

```
Balance Sheet-এ:

Asset-এর মূল্য $42 কমে
```

দুই দিকেই মিলে গেল—Double Entry।

# Chapter 4 : Depreciation Method

## 1. Straight Line (সবচেয়ে সাধারণ)

```
প্রতি মাসে সমান সমান

$2,000 ÷ 48 = $42 / মাস
```

## 2. Declining / Degressive

```
শুরুতে বেশি, পরে কম

(নতুন গাড়ি প্রথম বছরেই বেশি দাম হারায়)
```

# Chapter 5 : Asset-এর পুরো জীবন

```
কেনা

  ↓

ব্যবহার (প্রতি মাসে Depreciation)

  ↓

শেষে দুইটা ভাগ—

  ├── Sell (বিক্রি)  → Disposal

  └── ফেলে দেওয়া     → Write-off
```

---

## Disposal (Asset বিক্রি)

৪৮ মাস পরে Laptop-এর Book Value $0।

কিন্তু পুরোনো Laptop $200-এ বিক্রি হলো—

```
Debit    Bank                        $200

Debit    Accumulated Depreciation    $2,000

Credit   Laptop                      $2,000

Credit   Gain on Sale                $200
```

যদি Book Value থাকা অবস্থায় সস্তায় বিক্রি হতো—

```
Loss on Disposal (Expense)
```

হিসেবে যেত।

# Chapter 7 : Business Story

তোমার Software Company।

## জানুয়ারি : ১০টা Laptop কিনলে, মোট $20,000

```
Debit    Computer Equipment    $20,000

Credit   Bank                  $20,000
```

Asset Setup: ৪ বছর, Straight Line।

প্রতি মাসে—

```
$20,000 ÷ 48 = ~$417
```

---

## প্রতি মাসে (Automatic)

```
Debit    Depreciation Expense        $417

Credit   Accumulated Depreciation    $417
```

---

## ডিসেম্বর শেষে (১২ মাস পরে)

```
মোট Depreciation = $417 × 12 = $5,004

Book Value = $20,000 - $5,004 = $14,996
```

---

## ৩ বছর পর ১টা Laptop বিক্রি $300-এ

একটার কেনা দাম $2,000, Accumulated $1,500।

Book Value = $500।

```
Debit    Bank                        $300

Debit    Accumulated Depreciation    $1,500

Debit    Loss on Disposal            $200

Credit   Computer Equipment          $2,000
```

       │
       └── ফেলে দেওয়া → Write-off Loss

# Interview Questions

### 1. Fixed Asset কী?

**উত্তর:** ব্যবহারের জন্য কেনা, এক বছরের বেশি টেকে এমন সম্পদ—যেমন Laptop, Vehicle, Machine।

---

### 2. Depreciation কী?

**উত্তর:** Fixed Asset-এর মূল্য ব্যবহারের কারণে ধীরে ধীরে কমা—আর সেই কমতিকে প্রতি Period-এ Expense ধরা।

---

### 3. Laptop কেনার Entry কী?

**উত্তর:** Debit Laptop (Fixed Asset), Credit Bank। Expense হয় না।

---

### 4. Accumulated Depreciation কী?

**উত্তর:** আজ পর্যন্ত মোট কত Depreciation হয়েছে তার জমানো হিসাব—Asset-এর বিপরীত (Contra) Account।

---

### 5. Book Value কীভাবে বের হয়?

**উত্তর:** কেনা দাম − Accumulated Depreciation।

---

### 6. Straight Line Method কী?

**উত্তর:** Asset-এর মূল্য তার জীবনকালে সমান ভাগ করা—প্রতি মাসে একই Depreciation।

---

### 7. Asset বিক্রিতে Gain/Loss কীভাবে হয়?

**উত্তর:** বিক্রি মূল্য > Book Value হলে Gain, কম হলে Loss।

---

# Common Mistakes

❌ Laptop কেনাকে সরাসরি Expense ধরা—সে মাসে ভুল Loss দেখাবে।

❌ Asset-এর জীবনকাল (Duration) এলোমেলো ধরা।

❌ Accumulated Depreciation না বুঝে সরাসরি Asset Account Credit করা।

❌ Asset বিক্রির সময় Accumulated Depreciation উল্টাতে ভুলে যাওয়া।

❌ ছোট জিনিস (পেন, মাউস প্যাড) Asset বানানো—এগুলো সরাসরি Expense।

❌ Depreciation Entry Post করতে ভুলে যাওয়া—Profit বেশি দেখাবে।

# Module 11 শেষ করার পর তোমার যা বোঝা উচিত

* Fixed Asset = ব্যবহারের জন্য কেনা, বহু বছর টিকে।
* কেনার মুহূর্তে Expense না—Asset।
* প্রতি মাসে Depreciation Expense ধরা হয়।
* Accumulated Depreciation = মোট কত কমল।
* Book Value = কেনা দাম − Accumulated।
* Odoo প্রতি মাসে Automatic Depreciation Entry দেয়।
* বিক্রিতে Book Value-এর সাথে তুলনা করে Gain/Loss।
