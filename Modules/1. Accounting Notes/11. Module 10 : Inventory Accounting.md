# Module 10: Inventory Accounting — Odoo 19 Complete Note

এটাই Odoo Accounting-এর **সবচেয়ে গুরুত্বপূর্ণ Module**।

> **পণ্য কেনা মানে খরচ না। পণ্য বিক্রি হলে তখনই খরচ। মাঝখানে পণ্যটা Asset হিসেবে গুদামে শুয়ে থাকে। এই একটা Concept বুঝলে COGS, Profit, Inventory Valuation—সব ক্লিয়ার।**

# Chapter 1 : Real Life Story

ভাবো তুমি মোবাইলের দোকান খুললে।

১০টা ফোন কিনলে—একটা $200 করে।

```
মোট খরচ $2,000
```

প্রশ্ন—

**এই $2,000 কি এ মাসের খরচ?**

না!

কারণ ফোনগুলো তো গুদামে আছে।

তুমি না খাইয়ে ফেলেছো, না পুড়িয়ে ফেলেছো।

ফোনগুলো তোমার **সম্পদ**—কাল বিক্রি করেই টাকা আসবে।

---

এবার ৩টা ফোন বিক্রি হলো—একটা $300 করে।

```
বিক্রি পেলে      $900 (3 × $300)

কিন্তু খরচ কত?

শুধু ওই ৩টা ফোনের দাম = $600 (3 × $200)
```

তাহলে—

```
Profit = $900 - $600 = $300
```

এই "বিক্রি হওয়া পণ্যের কেনা দাম"-টাই হলো—

# Chapter 2 : Accounting Logic — দুই ধাপ

## ধাপ ১ : পণ্য কেনা (Expense না, Asset)

১০টা ফোন কিনলে $2,000—

```
Debit    Inventory (Asset)    $2,000

Credit   Accounts Payable     $2,000
```

> **Expense হয়নি! টাকার বদলে পণ্য এসেছে—Asset-এর রূপ বদলেছে মাত্র।**

---

## ধাপ ২ : পণ্য বিক্রি (দুইটা Entry হয় একসাথে)

৩টা ফোন $300 করে বিক্রি—

### Entry A : বিক্রির হিসাব

```
Debit    Accounts Receivable   $900

Credit   Sales Revenue         $900
```

### Entry B : খরচের হিসাব (COGS)

```
Debit    COGS (Expense)        $600

Credit   Inventory             $600
```

মানে—

```
গুদাম থেকে ৩টা ফোন বের হলো

↓

Inventory কমল $600

↓

সেটাই খরচ হিসেবে ধরা হলো
```

---

## পুরো চক্র একসাথে

```
Purchase

    ↓

Inventory (Asset-এ জমা)

    ↓

Sale

    ↓

COGS (খরচে চলে গেল)

    ↓

Profit = Sales - COGS
```

# Chapter 3 : কেন এত ঝামেলা? সরাসরি Expense করলে কী হয়?

ধরো ১০টা ফোন কেনাকে সরাসরি Expense ধরলে—

```
এই মাসে—

Sales    $900  (৩টা বিক্রি)

Expense  $2,000 (১০টা কেনা)

Loss     $1,100  ← ভুল!
```

অথচ আসলে তোমার $300 Profit!

৭টা ফোন গুদামে পড়ে আছে—ওগুলো তোমার সম্পদ।

> **Inventory ঠিকমতো Track না করলে Profit কখনোই সঠিক আসবে না।**

# Chapter 4 : Odoo-তে কীভাবে কাজ করে?

## দুইটা Mode আছে

### 1. Periodic (Manual)

```
Stock Move হলে কোনো Entry হয় না

মাস শেষে হাতে হিসাব করে Entry দিতে হয়
```

ছোট দোকানের জন্য।

### 2. Perpetual (Automated) ← Odoo-র শক্তি

```
পণ্য গুদামে ঢুকলেই Entry

পণ্য বের হলেই Entry

সব Automatic
```

---

## Perpetual-এ Odoo কী কী Entry বানায়?

### পণ্য Receive করলে (Vendor থেকে)

```
Debit    Inventory / Stock Valuation    $2,000

Credit   Stock Input (GRNI)             $2,000
```

### Vendor Bill Post করলে

```
Debit    Stock Input (GRNI)    $2,000

Credit   Accounts Payable      $2,000
```

### পণ্য Deliver করলে (Customer-কে)

```
Debit    Stock Output          $600

Credit   Inventory             $600
```

### Customer Invoice Post করলে

```
Debit    Accounts Receivable   $900

Credit   Sales Revenue         $900

আর—

Debit    COGS                  $600

Credit   Stock Output          $600
```

---

## GRNI / Stock Input কী?

```
Goods Received Not Invoiced
```

মানে—

```
"পণ্য এসে গেছে,

কিন্তু Bill এখনো আসেনি"
```

এটা একটা Temporary Bridge Account—

```

```

# Chapter 5 : Inventory Valuation — পণ্যের দাম কোনটা?

ধরো একই ফোন দুইবার কিনলে—

```
১ম বার : ৫টা × $200 = $1,000

২য় বার : ৫টা × $220 = $1,100
```

এখন একটা বিক্রি হলো—

**COGS-এ কত ধরবে? $200 নাকি $220?**

তিনটা নিয়ম আছে—

---

## 1. FIFO (First In First Out)

```
আগেরটা আগে বিক্রি

COGS = $200
```

যেমন দোকানের তাকে আগের মাল সামনে থাকে।

## 2. AVCO (Average Cost)

```
($1,000 + $1,100) / 10টা = $210

COGS = $210
```

## 3. Standard Price

```
নিজে একটা দাম ঠিক করে রাখো, যেমন $205

সব বিক্রিতে $205 ধরবে

পার্থক্য Price Difference Account-এ যায়
```

---

Odoo-তে Product Category-তে Set করা থাকে—

```
Inventory

↓

Configuration

↓

Product Categories

↓

Costing Method : FIFO / AVCO / Standard

Inventory Valuation : Automated / Manual
```

# Interview Questions

### 1. পণ্য কেনা কি Expense?

**উত্তর:** না। পণ্য কেনা মানে Inventory (Asset) বাড়া। Expense হয় যখন পণ্য বিক্রি হয়—তখন COGS হিসেবে।

---

### 2. COGS কী?

**উত্তর:** Cost of Goods Sold—বিক্রি হওয়া পণ্যের কেনা দাম। Profit = Sales − COGS।

---

### 3. Perpetual আর Periodic Inventory-র পার্থক্য?

**উত্তর:** Perpetual-এ প্রতিটা Stock Move-এ Automatic Journal Entry হয়; Periodic-এ মাস শেষে হাতে হিসাব করে Entry দিতে হয়।

---

### 4. FIFO কী?

**উত্তর:** First In First Out—আগে যে পণ্য কেনা, সেটার দামে আগে COGS ধরা হয়।

---

### 5. GRNI / Stock Input Account কী?

**উত্তর:** Goods Received Not Invoiced—পণ্য এসেছে কিন্তু Bill আসেনি, এই সময়ের ফারাক সামলানোর Temporary Account।

---

### 6. Inventory ভুল দেখালে কী হয়?

**উত্তর:** COGS ভুল আসে → Profit ভুল আসে → Tax ও Business Decision—সব ভুল হয়।

---

### 7. বিক্রিতে কয়টা Journal Entry হয়?

**উত্তর:** দুইটা—একটা Sales-এর (Dr Receivable / Cr Sales), একটা COGS-এর (Dr COGS / Cr Inventory)।

---

# Common Mistakes

❌ পণ্য কেনাকে সরাসরি Expense ধরা—Profit গুলিয়ে যায়।

❌ Perpetual Valuation চালু করে Stock Account Setup না করা।

❌ Costing Method (FIFO/AVCO) না বুঝে রিপোর্ট বিশ্বাস করা।

❌ Receive আর Bill-এর Entry দুইবার করে ফেলা।

❌ Physical Stock না গোনা—Book আর গুদাম মিলে না।

❌ Service Product-এ Inventory Tracking চালু করা (Service-এর Stock হয় না)।

# Module 10 শেষ করার পর তোমার যা বোঝা উচিত

* পণ্য কেনা = Asset (Inventory), Expense না।
* পণ্য বিক্রি = দুইটা Entry—Sales আর COGS।
* Profit = Sales − COGS।
* Perpetual Mode-এ Odoo প্রতিটা Stock Move-এ Entry বানায়।
