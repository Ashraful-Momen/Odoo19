# Module 13: Fiscal Year — Odoo 19 Complete Note

আজ আমরা শিখব **Accounting বছর কীভাবে শুরু আর শেষ হয়**।

> **প্রতি বছরে Income-Expense শূন্য থেকে শুরু হয়, কিন্তু Asset-Liability চলতে থাকে। এই "কোনটা শূন্য হয়, কোনটা বয়ে যায়"—এটাই Fiscal Year-এর মূল জাদু।**

---

# Chapter 1 : Real Life Story

ভাবো তুমি প্রতি বছর একটা নতুন খাতা কেনো।

পুরোনো বছরের খাতা বন্ধ করে দাও।

কিন্তু সবকিছু কি শূন্য থেকে শুরু হয়?

না—

```
Bank-এ যে টাকা আছে

→ নতুন খাতায়ও সেটা আছে
```

```
Customer-এর পাওনা

→ নতুন বছরেও পাওনা
```

কিন্তু—

```
গত বছরের Sales

→ নতুন বছরে আবার শূন্য থেকে গোনা শুরু
```

ঠিক এই কাজটাই Accounting-এ হয় প্রতি বছর শেষে।

# Chapter 2 : Fiscal Year কী?

Company-র Accounting বছর।

```
জানুয়ারি → ডিসেম্বর   (Calendar Year)
```

বা

```
জুলাই → জুন            (বাংলাদেশে প্রচলিত)
```

একই ব্যাপার—শুধু শুরু-শেষের Date আলাদা।

---

# Chapter 3 : বছর শেষে দুই ধরনের Account-এর ভাগ হয়

## 1. Permanent Account (বয়ে যায়)

```
Asset      → Bank, Inventory, Laptop

Liability  → Loan, Payable, VAT

Equity     → Capital, Retained Earnings
```

এগুলোর Balance—

```
নতুন বছরে যেমন ছিল তেমনি চলে যায়
```

কারণ সম্পদ আর দেনা তো বছর বদলালেই শেষ হয় না।

---

## 2. Temporary Account (শূন্য হয়)

```
Income    → Sales, Service Income

Expense   → Salary, Rent, COGS
```

এগুলোর Balance—

```
নতুন বছরে আবার ০ থেকে শুরু
```

কারণ "এই বছর কত বিক্রি"—এটা প্রতি বছর আলাদা গল্প।

---

## কিন্তু শূন্য হলে টাকাটা গেল কোথায়?

Income আর Expense-এর পার্থক্য মানেই তো Profit।

সেই Profit বন্ধ হওয়া Account-গুলো থেকে চলে যায়—

```
Retained Earnings (Equity)
```

-এ।

---

# Chapter 4 : Closing Entry — বছর বন্ধ করা

## কী হয়?

ধরো এই বছর—

```
Sales          $50,000

সব Expense     $30,000

─────────────────────

Profit         $20,000
```

বছর শেষে—

```
সব Income Account শূন্য

সব Expense Account শূন্য

পার্থক্য $20,000 → Retained Earnings
```

ধারণাগত Entry—

```
Debit    Sales (শূন্য করা)        $50,000

Credit   Expense (শূন্য করা)      $30,000

Credit   Retained Earnings        $20,000
```

---

## Odoo-তে কী হয়?

সুখবর—

```
Odoo নিজেই সব করে

তোমাকে হাতে Closing Entry দিতে হয় না
```

নতুন Fiscal Year শুরু হলে Odoo Automatic—

```
Income / Expense → 0 থেকে Report শুরু

Profit → Retained Earnings-এ যোগ

Asset / Liability → আগের Balance-ই চলে
```

---

# Chapter 5 : Opening Entry — নতুন বছরের শুরু

## কখন লাগে?

দুই ক্ষেত্রে—

```
১. একদম নতুন Company

   প্রথমবার Odoo-তে হিসাব শুরু

   পুরোনো খাতার Balance গুলো ঢুকাতে হবে
```

```
২. নতুন Software-এ Migrate

   আগের System-এর Closing Balance

   → এখানকার Opening Balance
```

---

## Example

পুরোনো খাতা থেকে—

```
Bank                $10,000

Inventory           $5,000

Receivable          $2,000

Loan                $3,000

Capital            $14,000
```

Opening Entry (Miscellaneous Journal-এ)—

```
Debit    Bank                 $10,000

Debit    Inventory            $5,000

Debit    Receivable           $2,000

Credit   Loan                 $3,000

Credit   Capital              $14,000
```

```
Debit = Credit = $17,000 ✓
```

---

## Odoo Screen

```
Accounting → Accounting → Journal Entries

Journal: Miscellaneous (বা Opening Journal)

Date: বছরের প্রথম দিন

Lines: সব Opening Balance
```

# Chapter 6 : Lock Date — বছর (আর মাস) তালাবদ্ধ করা

## সমস্যাটা কী?

ধরো ২০২৫-এর Report Final হয়ে গেছে,

Tax দেওয়া শেষ।

এখন কেউ ভুল করে ২০২৫-এর ডিসেম্বরে

একটা Entry বদলে দিলে?

```
Report বদলে যাবে

Tax বদলে যাবে

সব গুলিয়ে যাবে
```

---

## সমাধান

```
Lock Date
```

মানে—

```
এই Date-এর আগে কোনো Entry

তৈরি / বদলানো / Delete

করা যাবে না
```

---

## Odoo-তে Lock Date-এর ধরন

```
Sales Lock Date

   → আগের Invoice বন্ধ

Purchase Lock Date

   → আগের Bill বন্ধ

Tax Lock Date

   → Tax Report Lock

All Users Lock Date

   → সবকিছু বন্ধ (Accountant ছাড়া)

Hard Lock Date

   → কেউই পারবে না
```

---

## Odoo Screen

```
Accounting → Accounting → Lock Dates
```

> **Rule of thumb: মাস শেষ + Report Final = Lock Date দাও। বছর শেষে Hard Lock।**

# Chapter 7 : Carry Forward

মানে—

```
পুরোনো বছরের Balance

→ নতুন বছরে বয়ে নেওয়া
```

```
Asset / Liability / Equity

→ Balance Carry Forward হয়
```

```
Income / Expense

→ Carry হয় না, শূন্য থেকে শুরু

→ শুধু তাদের পার্থক্য (Profit)

   Retained Earnings-এ যোগ হয়
```

# Chapter 8 : Business Story — এক বছরের পুরো Cycle

তোমার Software Company, ২০২৬।

## জানুয়ারি ১ : Opening

গত বছরের Balance বয়ে এলো—

```
Bank                $8,000

Receivable          $2,000

Capital            $10,000
```

Income-Expense শূন্য।

---

## পুরো বছর

```
Sales              $50,000

Expense            $30,000

Profit             $20,000
```

প্রতি মাস শেষে—

```
Report দেখা ✓

Tax দেওয়া ✓

মাস Lock করা ✓
```

---

## ডিসেম্বর ৩১ : বছর শেষ

```
১. সব Adjustment Entry ✓

২. Depreciation সব মাসের Post ✓

৩. Bank Reconcile ✓

৪. Tax Report Final ✓
```

তারপর Odoo নিজে—

```
Income / Expense → শূন্য

Profit $20,000 → Retained Earnings

Capital এখন: $10,000 + $20,000 = $30,000
```

---

## জানুয়ারি ১, ২০২৭

```
Asset / Liability  → আগের মতোই

Retained Earnings  → $20,000 বাড়তি

Sales / Expense    → আবার ০ থেকে

Hard Lock Date     → ৩১/১২/২০২৬
```

নতুন বছর শুরু।

# Complete Fiscal Year Structure

```
Fiscal Year
│
├── Opening Entry
│      │
│      └── আগের Balance ঢোকানো
│          (নতুন Company/Migration)
│
├── পুরো বছর
│      │
│      ├── Entry / Invoice / Payment
│      │
│      ├── মাস শেষে Report + Lock
│      │
│      └── Adjustment Entry
│
├── Closing (বছর শেষে)
│      │
│      ├── Income/Expense শূন্য
│      │
│      └── Profit → Retained Earnings
│
├── Lock Date
│      │
│      └── পুরোনো Period-এ হাত দেওয়া যাবে না
│
└── Carry Forward
       │
       └── Asset/Liability/Equity নতুন বছরে
```

# Interview Questions

### 1. Fiscal Year কী?

**উত্তর:** Company-র Accounting বছর—যেমন জানুয়ারি-ডিসেম্বর বা জুলাই-জুন—যার শেষে বছরের হিসাব বন্ধ হয়।

---

### 2. Permanent আর Temporary Account-এর পার্থক্য?

**উত্তর:** Asset/Liability/Equity (Permanent) নতুন বছরে Balance বয়ে যায়; Income/Expense (Temporary) প্রতি বছর শূন্য থেকে শুরু হয়।

---

### 3. বছর শেষে Profit কোথায় যায়?

**উত্তর:** Retained Earnings (Equity)-তে—তাই মালিকের সম্পদ বাড়ে।

---

### 4. Opening Entry কখন লাগে?

**উত্তর:** নতুন Company বা নতুন Software-এ Migrate করলে—পুরোনো Balance গুলো প্রথমবার ঢোকাতে।

---

### 5. Lock Date কেন দরকার?

**উত্তর:** Final হওয়া Period-এ ভুল করে Entry বদলানো/Delete বন্ধ করতে—নাহলে পুরোনো Report ও Tax গুলিয়ে যায়।

---

### 6. Odoo-তে Closing Entry হাতে দিতে হয়?

**উত্তর:** না। Odoo নিজেই Income/Expense শূন্য করে আর Profit Retained Earnings-এ নিয়ে যায়।

---

# Common Mistakes

❌ Opening Entry-তে Debit-Credit না মেলা।

❌ Receivable-এর Opening Balance-এ Partner না দেওয়া।

❌ Lock Date না দেওয়া—পুরোনো বছরে ভুল Entry ঢুকে যায়।

❌ বছর শেষের আগে Adjustment/Depreciation বাদ দেওয়া।

❌ Opening Balance দুইবার ঢুকানো (Migration-এর সময়)।

❌ Fiscal Year-এর Date ভুল Setup করা।

```
গ. কোন Account-গুলো ২০২৭-এ Balance নিয়ে যাবে? কোনগুলো শূন্য হবে?

```
