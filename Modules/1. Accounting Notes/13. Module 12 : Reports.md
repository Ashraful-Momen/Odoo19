আজ আমরা শিখব **সব Entry-র ফলাফল কোথায় দেখা যায়**।

> **Entry করা হলো কাজের কাজ। কিন্তু মালিক জিজ্ঞেস করবে—"লাভ কত? পাওনা কত? Bank-এ কত?" এই উত্তরগুলোই Report। আর ভালো খবর—Odoo-তে Report বানাতে হয় না, সব নিজে থেকেই তৈরি।**

# Chapter 1 : Real Life Story

ভাবো তুমি একটা দোকানের Manager।

মাস শেষে মালিক এসে ৫টা প্রশ্ন করল—

```
১. "এ মাসে লাভ কত?"           → Profit & Loss

২. "দোকানের সম্পদ কত?"         → Balance Sheet

৩. "কে কত টাকা দেবে?"          → Aged Receivable

৪. "আমরা কাকে কত দেব?"         → Aged Payable
```

এই ৫টা প্রশ্নের উত্তরই Accounting Report।

আর Odoo-তে এগুলো আছে Ready-made—

শুধু Date Select করে দেখলেই হবে।

# Chapter 3 : Trial Balance — প্রথম Check

## কী?

সব Account-এর Debit-Credit Balance এক পাতায়।

```
Account                 Debit       Credit

Bank                    12,500

Accounts Receivable      3,000

Inventory                1,300

Accounts Payable                     550

Owner Capital                      10,000

Sales Revenue                       6,750

Salary Expense             500

─────────────────────────────────────

Total                   17,300      17,300   ✓
```

## কেন দরকার?

```
Debit Total = Credit Total?

↓

হ্যাঁ → Entry-গুলো ঠিক আছে

না  → কোথাও ভুল আছে
```

> **Trial Balance মানে— "সব Entry ঠিকমতো হয়েছে" এই Final Exam।**

## Odoo Screen

```
Accounting → Reporting → Trial Balance
```

# Chapter 4 : Profit & Loss (P&L)

## কী?

একটা সময়ের (মাস/বছর) ব্যবসার ফলাফল—

```
Revenue (আয়)

   Software Sales          $6,750

Expense (খরচ)

   Salary                   $500

   Hosting                  $150

   Depreciation              $42

──────────────────────────────

Net Profit                 $6,058
```

## Logic

```
সব Income Account-এর Credit জমা

−

সব Expense Account-এর Debit জমা

=

Profit (বা Loss)
```

## Odoo Screen

```
Accounting → Reporting → Profit and Loss
```

Date Range দাও—রেডি।

# Chapter 5 : Balance Sheet

## কী?

একটা নির্দিষ্ট দিনে Company-র ছবি—

```
কী কী আছে (Asset)

=

কার কাছে দেনা (Liability) + মালিকের (Equity)
```

```
ASSETS

   Bank                    12,500

   Receivable               3,000

   Inventory                1,300

   Laptop (Net)             1,958

                              18,758

LIABILITIES

   Payable                    550

   VAT Payable                150

                                 700

EQUITY

   Capital                 10,000

   Retained Profit          8,058

                              18,758   ✓
```

## মনে রাখো

```
Assets = Liabilities + Equity

সবসময় মিলবে।

না মিললে কোথাও ভুল।
```

## P&L আর Balance Sheet-এর পার্থক্য

| Profit & Loss         | Balance Sheet           |
| --------------------- | ----------------------- |
| একটা সময়ের (মাস/বছর)  | একটা দিনের ছবি          |
| Income vs Expense     | Asset vs Liability+Equity|
| "লাভ কত?"             | "অবস্থা কেমন?"           |

## Odoo Screen

```
Accounting → Reporting → Balance Sheet
```

# Chapter 8 : Aged Receivable — কে কত দিন ধরে দেবে

```

ABC Corp                2,000

────────────────────────────────────────────────────

Total          1,500    2,000        0       800       0
```

## কেন দরকার?

```

→ Follow-up করো

→ আর বাকি দিও না
```


# Interview Questions

### 1. Trial Balance কী?

**উত্তর:** সব Account-এর Debit-Credit Balance-এর তালিকা—Debit Total আর Credit Total মিললেই Entry-গুলো আংশিকভাবে ঠিক বোঝায়।

---

### 2. Profit & Loss আর Balance Sheet-এর পার্থক্য?

**উত্তর:** P&L একটা সময়ের Income-Expense-এর ফলাফল (লাভ কত), Balance Sheet একটা দিনের Asset-Liability-Equity-এর ছবি (অবস্থা কেমন)।

---

### 3. General Ledger কখন দেখবে?

**উত্তর:** কোনো Account-এর বিস্তারিত লেনদেন দেখতে বা ভুল খুঁজতে—প্রতিটা লাইন থেকে আসল Entry পর্যন্ত যাওয়া যায়।

---

### 4. Aged Receivable কী?

**উত্তর:** Customer-এর পাওনা কত দিন পুরোনো সেভাবে ভাগ করা Report—যা Follow-up ও Risk বোঝাতে সাহায্য করে।

---

### 5. Balance Sheet কেন সবসময় মিলে?

**উত্তর:** কারণ প্রতিটা Entry-তে Debit = Credit, তাই Assets = Liabilities + Equity সবসময় সত্য থাকে।

---

### 6. Draft Entry Report-এ আসে?

**উত্তর:** না। শুধু Posted Entry Report-এ আসে।

---

# Common Mistakes

❌ Draft Entry ভুলে থেকে Report ভুল ভাবা।

❌ ভুল Date Range দিয়ে Report দেখা।

❌ Trial Balance মিললেই ভাবা সব ঠিক—ভুল Account-এ Entry থাকলেও মিলে।

❌ Aged Receivable না দেখা—পুরোনো পাওনা ডুবে যায়।

❌ P&L দেখে Bank Balance আন্দাজ করা—লাভ আর Cash এক না।

❌ Report-এর সংখ্যা না বুঝে মালিককে দেওয়া।
