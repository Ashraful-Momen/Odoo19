# Module 7: Customer — Odoo 19 Complete Note

আজ আমরা শিখব **Customer Side-এর পুরো Accounting Cycle**।

> **Invoice → Credit Note → Payment → Receipt—এই চাইটা জিনিস বুঝলে Customer Accounting শেষ। আর সবগুলোই আসলে `account.move`-এর ভিন্ন রূপ।**

---

# Chapter 1 : Real Life Story

ভাবো তুমি একটা দোকানদারের কাছে খাতা রাখো।

Customer আসলে কী কী ঘটে?

```
১. কাস্টমার পণ্য নিল, বাকি রাখল

   → খাতায় পাওনা লেখা (Invoice)
```

```
২. কাস্টমার পণ্য ফেরত দিল

   → পাওনা কমানো (Credit Note)
```

```
৩. কাস্টমার টাকা দিল

   → পাওনা শোধ (Payment)
```

```
৪. টাকা দেওয়ার রশিদ দিলে

   → Receipt
```

এই চাইটাই Customer Accounting-এর পুরো জীবন।

# Chapter 3 : Credit Note — Customer পণ্য ফেরত দিলে

## কখন লাগে?

```
পণ্য ফেরত এলো

দাম ভুল লেখা হয়েছিল

বিক্রির পর Discount দিতে হলো

Service বাতিল হলো
```

---

## Credit Note-এর Entry (Invoice-এর উল্টোটা)

```
Debit    Sales Return / Revenue    $500

Credit   Accounts Receivable       $500
```

মানে—

```
Customer-এর পাওনা কমে গেল
```

---

## Odoo-তে কীভাবে বানাবে?

```
   ২. Partial Refund (কিছু অংশ)

   ৩. Full refund and new draft invoice

      (ভুল Invoice বাতিল + নতুন সঠিক Invoice)
```

# Chapter 5 : Business Story — এক Customer-এর পুরো গল্প

তোমার Software Company।

Customer: **ABC Corporation**

---

## ঘটনা ১ : Invoice

```
Software License বিক্রি $5,000

VAT 15% = $750

মোট = $5,750
```

Entry—

```
Debit    Accounts Receivable (ABC)   $5,750

Credit   Software Sales              $5,000

Credit   VAT Payable                 $750
```

---

## ঘটনা ২ : Partial Payment

ABC দিল $3,000।

```
Debit    Bank                        $3,000

Credit   Accounts Receivable (ABC)   $3,000
```

```
Invoice State: Partial

Outstanding: $2,750
```

---

## ঘটনা ৩ : Credit Note

একটা Service ঠিকমতো হয়নি—$500 কমিয়ে দিলে।

```
Debit    Software Sales              $500

Credit   Accounts Receivable (ABC)   $500
```

```
Outstanding এখন: $2,250
```

---

## ঘটনা ৪ : Final Payment

ABC বাকি $2,250 দিল।

```
Debit    Bank                        $2,250

Credit   Accounts Receivable (ABC)   $2,250
```

```
Invoice State: Paid ✓

Outstanding: $0
```

---

## ABC-এর Receivable হিসাব

```
+5,750 (Invoice)

-3,000 (Payment)

-500   (Credit Note)

-2,250 (Payment)

= 0  → সব শোধ ✓
```

# Interview Questions

### 1. Customer Invoice-এর Journal Entry কী?

**উত্তর:** Debit Accounts Receivable, Credit Sales Revenue (Tax থাকলে আলাদা Credit Tax Account)।

---

### 2. Credit Note কখন ব্যবহার করবে?

**উত্তর:** পণ্য ফেরত, দাম ভুল, বিক্রির পর Discount বা Service বাতিল হলে—Customer-এর পাওনা কমাতে।

---

### 3. Credit Note-এর Entry কী?

**উত্তর:** Debit Sales (Return), Credit Accounts Receivable—Invoice-এর উল্টো।

---

### 4. Odoo-তে Invoice আর Credit Note কি আলাদা Table-এ থাকে?

**উত্তর:** না। দুটোই `account.move`—Invoice হলো `out_invoice`, Credit Note হলো `out_refund`।

---

### 5. Receipt আর Invoice-এর পার্থক্য?

**উত্তর:** Invoice মানে "টাকা দিতে হবে" (বাকিতে বিক্রি), Receipt মানে "টাকা পেয়েছি" (নগদ বিক্রির প্রমাণ)।

---

### 6. Posted Invoice ভুল হলে কী করবে?

**উত্তর:** Delete করা যাবে না। Credit Note দিয়ে উল্টে দিতে হবে, তারপর নতুন সঠিক Invoice।

---

# Common Mistakes

❌ ভুল Invoice Delete করতে চেষ্টা করা—Credit Note দিতে হয়।

❌ Credit Note-এর বদলে নতুন Manual Entry করা।

❌ Payment-এর সময় Manual Entry—Register Payment ব্যবহার করো।

❌ Invoice-এ Due Date / Payment Terms না দেওয়া—Follow-up কঠিন হয়।

❌ Customer-এর Receivable Account ভুল Setup করা।

❌ Draft Invoice ভুলে যাওয়া—Confirm করাই হয়নি, Sales-ই হয়নি।

# Module 7 শেষ করার পর তোমার যা বোঝা উচিত

* Customer Cycle = Invoice → (Credit Note) → Payment → Paid।
* Invoice = `out_invoice`, Credit Note = `out_refund`—দুটোই `account.move`।
* Invoice Post করলেই Odoo নিজে Journal Entry বানায়।
* ভুল Invoice কখনো Delete না—সবসময় Credit Note।
* Receipt মানে টাকা পাওয়ার প্রমাণ।
* Customer Master থাকে `res.partner`-এ।
